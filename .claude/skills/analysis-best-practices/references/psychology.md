# 分析に心理学を組み込む

数字がどう動いたかを正しく分析できても、その数字を作っている「人」がどう感じ、何に動機づけられ、
何を恐れて行動しているかを踏まえないと、正しい施策にたどり着けない。統計的に正しい分析の先には、
必ず人の心理がある。以下は、行動経済学・認知心理学・学習科学から実証されている原則と、
その応用/悪用の実例。

## 1. プロスペクト理論と損失回避（Kahneman & Tversky）

人は同額の利得より損失を強く感じる（研究では約2倍とされる）。利益が出ている局面ではリスクを
避けて早く確定したくなり（早すぎる利確）、損失が出ている局面では損を取り戻そうとリスクを
取りたくなる（塩漬け）。

- **裏付けとなる実例（気質効果 / Disposition Effect）**: 1985年にShefrinとStatmanが命名し、
  Terrance Odeanが1万件の証券口座を分析して実証した。投資家は客観的には保有すべきでない
  「勝ち銘柄」を早く売り、「負け銘柄」を長く塩漬けにする傾向が一貫して見られた。損失を出す
  ほど、この傾向はさらに強まり、損失を拡大させる悪循環に陥ることも確認されている。
- **応用（dividend アプリ）**: 含み損・含み益の表示は、投資家がこの心理的な罠にはまりやすい
  ことを前提に設計する。「下がっているから危ない」ではなく、機械的な事実と、感情的に判断を
  誤りやすいタイミング（大きな含み損・含み益が出ている局面）を分けて示す。

## 2. メンタル・アカウンティング（Thaler）

人はお金の出どころ・使いみちによって心理的に別の「勘定科目」に分けて扱い、同じ金額でも
意思決定が変わる（ボーナスは浪費しやすく、給与は堅実に使われやすい、など）。

- **応用（cashbook アプリ）**: 「臨時収入」「特別支出（冠婚葬祭・家電の買い替え）」は通常の
  月次支出と心理的に別枠で扱われがちである。支出分析のカテゴリ分けや警告は、この心理的な
  区分けのクセを踏まえて設計する（`checklist.md` の一時支出の除外ルールとも整合する）。

## 3. 慣性・デフォルトの力を使ったナッジ（Save More Tomorrow, Thaler & Benartzi）

意思決定の手間や「今の手取りが減る」という損失回避を避ける設計にすると、行動が大きく変わる。
「Save More Tomorrow」プログラムは、貯蓄率の引き上げを「将来の昇給分だけ」に連動させ
（手取りが今減らない＝損失回避を回避）、一度加入したら自動継続（＝慣性を利用）にすることで、
参加者の平均貯蓄率を3.5%から40ヶ月で13.6%まで引き上げ、現在は米国の大手退職金制度の大半で
採用されている。
→ **応用**: 貯蓄・積立・継続を促す施策は、「今すぐ我慢させる」ではなく「痛みの少ないタイミング
（収入が増えた時など）」「デフォルトで有効」を検討する。

## 4. 想起練習と分散学習（Testing Effect / Retrieval Practice）

読み返す（再学習）よりも、思い出す行為（テスト形式で答える）そのものが記憶の定着を強める
ことが数多くの研究で示されている。242研究・16万人超を対象にしたメタ分析でも、
「分散練習（distributed practice）」と「テスト形式の練習（practice testing）」の組み合わせが
最も効果的な学習法とされている。
また、想起練習は試験不安を下げ、自信を高める効果も確認されている。

→ **応用（yosou / sekaishi アプリ）**: 「読むだけ」の解説コンテンツより、問題形式で解かせて
間隔を空けて再出題する設計の方が学習効果が高い。予想・出題傾向の分析だけでなく、
アプリの出題順序・復習タイミングの設計にもこの原則を反映する。

## 5. 内発的動機づけと外的報酬の逆効果（自己決定理論・アンダーマイニング効果）

自律性・有能感・関係性が満たされると人は内発的に動機づけられるが、ポイントや連続記録
（ストリーク）などの外的な報酬・圧力に頼りすぎると、報酬が途切れた途端にやる気を失ったり、
報酬のための行動（見せかけの継続）に置き換わったりする（アンダーマイニング効果）。

→ **応用**: 継続率・利用頻度を分析するとき、「通知を増やす」「連続記録を煽る」施策は短期的な
継続率は上げても、長期的な満足度や本質的な利用意欲を損なう可能性がある。数字が上がった理由が
「本当に役立っているから」か「外的な圧力に反応しているだけ」かを区別する。

## 6. エンゲージメント最適化の倫理的境界（YouTubeのwatch time最適化問題、2019年）

「視聴時間」という単一指標を最大化するように設計されたレコメンドアルゴリズムが、より刺激的・
扇動的なコンテンツへ視聴者を誘導しやすいという批判を招き、YouTubeは2019年にアルゴリズムを
修正して、問題のあるコンテンツの推薦による視聴時間を50%以上削減したと発表した。
→ **教訓**: 単一の行動指標（視聴時間・クリック率）を無条件に最大化する施策は、対象者の
心理的な健全性（依存・後悔・扇動されやすさ）を犠牲にする副作用を生みやすい。数字の最大化と
利用者の満足・信頼が一致しているかを、施策を提案するたびに確認する。

## 分析に組み込むときの型

- 数字（What）を報告するときは、その裏にいる人が何を感じ、何を恐れ、何に動機づけられて
  その行動を取ったか（Why, psychologically）を一言添えられるか考える。
- 施策を提案するときは、「痛みの少ないタイミング」「デフォルトの力」「損失回避の回避」など、
  行動経済学の知見で後押しできないか検討する（精神論で「もっと頑張ろう」と言うだけにしない）。
- 短期的な行動指標（クリック・連続記録・通知への反応）の最大化が、長期的な満足・信頼・
  健全な利用を犠牲にしていないか、YouTubeの事例を踏まえて自己点検する。
