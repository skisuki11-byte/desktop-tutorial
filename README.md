# 日大基礎学 英単語 一問一答

日本大学付属高校の **基礎学力到達度テスト［英語］** 対策アプリ。
令和2年度9月〜令和5年度9月の**過去問7回分を実際に読み込んで分析**し、
「点数に直結する語彙」だけを一問一答にしたブラウザアプリです。

## 使い方

`index.html` をブラウザで開くだけ。インストール・ビルド・通信は一切不要で、
スマホでもオフラインで動きます。学習記録は端末内（localStorage）に保存されます。

## 機能

- **一問一答** … 問題 →「答えを見る」→ わかった／あやふや／わからない で自己採点
- **4択クイズ** … 本番と同じ形式。誤答選択肢の意味も解説に表示
- **苦手だけ** … 間違えた問題だけを集中復習
- **一覧で確認** … 検索付きで一気に眺める
- **進捗記録** … 習得率リング／苦手数／連続学習日数
- 出典タグ付き（`R3-4 問7（実出題）` のように、実際に出た問題が一目で分かる）
- キーボード操作（`Space` で答え表示、`1`/`2`/`3` で自己採点、数字キーで選択肢）
- ダークモード対応

## 出題分析（要約）

詳細は [`docs/出題分析.md`](docs/出題分析.md)、またはアプリ内「出題分析を見る」から。

### 4月型と9月型で大問構成が違う

- **4月型**：大問2(A)に「英英定義→単語」、2(B)に「連語」が独立して出る → **語彙対策が直接点になる**
- **9月型**：大問4の「長文空所補充」が9問 → **実質は語彙テスト**

### 差がつくポイント

1. **英英定義**は定義文が平易。誤答選択肢が似た綴りで揃えられる
   （`competition / completion / corporation / contradiction`）→ **綴りが似た語をセットで暗記**
2. **接続表現が毎回1〜2問**出る。特に `while`（〜する間／〜だが）は **3回**出題
3. **文法は論点が固定**。付帯状況 `with + O + 分詞` は2回出題。13論点を潰せば満点圏
4. 長文テーマは統計・調査／テクノロジー／環境・社会／生物・科学の4系統に集中。
   `survey / percentage / participant / reveal / indicate / figure / majority` は全年度で登場

## 出典について

過去問は画像（写真）から読み取って作成しています。
`real: true` が付いた項目は実際に出題された問題、`類題`／`予想` は同形式・同レベルで作成したものです。
