# レバレッジ型ブルベア投信の自動売買｜検証記録

社内のセミナー企画（Notion「ミーティング 2026-08-19」）で紹介された戦略——
**「レバレッジ型投資信託（ブル商品）を毎日積み立てて買い、
上昇時に利益確定→買い直しを繰り返す複利運用」（過去実績・年率14%以上と説明）**
——を実データで検証した記録。

FXの検証プロジェクト（`fx/`）と同じ規律で進める：
マーケティング上の主張を、検証可能な形に具体化し、実データで敵対的に検証する。

## 結論（先に読むところ）

### 1. この資産クラスはFXと構造がまったく違う

| | FX | レバレッジ型ブルベア投信 |
|---|---|---|
| レバレッジの出所 | 業者の証拠金取引（口座・審査が必要） | **ファンド自体に内蔵**（信託約款で「原指数の日次リターンの2倍」等と規定） |
| 主要コスト | スプレッド・スリッページ | **信託報酬**（年0.8〜1%程度）＋**ボラティリティ減衰**（後述） |
| 執行 | リアルタイム約定 | 投信は基準価額（1日1回）。ETF版は取引所でリアルタイム |
| 税制 | 申告分離20.315% | 同じ20.315%（特定口座）。ETF版は成長NISA対象の場合あり |

**口座開設・API契約のハードルがFXよりずっと低い。** 通常の証券口座があれば
即座に売買できる。これがこの資産クラスを検討する最大の動機。

### 2. 中心的なリスクは「スプレッド」ではなく「ボラティリティ減衰」

レバレッジ型ファンドは毎日リバランスするため、**原指数が変わらなくても、
ボラティリティの分だけ確実に目減りする。** これは執行の巧拙とは無関係の
数学的事実で、FXにおける「shift + spread」に相当する死守すべき前提。

決定論的な往復相場（+5%→-5%を500回）で検算：原指数はほぼ横ばい（-71.4%…
実際にはこの極端な例では原指数自体も大きく減衰するが、後述のとおり
**2倍側は-99.3%までさらに溶ける**）。方向とは無関係に、変動そのものが
コストになる。

### 3. 「単純に買って持つ」は、直近の現実的な局面ではほぼ全て悲惨

日経平均の実データ（1949-2020年、macrotrends由来）で2倍レバレッジの
単純買い持ちを検証：

| 期間 | 原指数CAGR | レバ買い持ちCAGR(信託報酬込) |
|---|---|---|
| 1949-1990（高度成長〜バブル） | +14.3% | **+26.2%** |
| 1990-2020（バブル崩壊後30年） | -2.4% | **-10.8%** |
| 2000-2020（20年） | +0.0%（ほぼ横ばい） | **-6.3%** |
| 2010-2020（異次元緩和10年） | +6.0% | +6.4% |

**原指数がほぼ横ばいの20年間で、レバレッジ側は-67%〜-72%まで目減りする。**
1949-1990年の超長期ブル相場だけが例外で、その再来を前提にはできない。

### 4. セミナーの戦略を検証：解釈次第で結果が桁違いに変わった

「毎日積み立てて買い、上昇時に利確→買い直し」という説明は曖昧で、
**利確した現金をどう再投資するか**の書き分けがない。2通りに具体化して比較：

| 期間 | レバ買い持ち | **A) 定額積立**（現金の額に関わらず毎日$1ずつ） | **B) 全額再投資**（文字通りの複利） |
|---|---|---|---|
| 1949-1990 | +26.2% | **-9.4%（壊滅）** | +22.7%（MOIC 3,900倍） |
| 1990-2020 | -10.8% | -15.6% | **-0.2%（ほぼ元本維持）** |
| 2000-2020 | -6.3% | -20.8% | **+1.3%** |
| 2010-2020 | +6.4% | -33.0% | +3.9% |
| リーマン含む3年 | -37.1% | -67.8% | **-6.0%** |

**解釈Aは、年率+14%の超長期ブル相場ですら資金をほぼ全損させる。**
毎日固定額しか再投資しないと、利確で得た現金が積み上がるだけで、
複利ではなく「線形の細い流れ」にしかならないため
（[dca_realize.py](dca_realize.py) のコメント参照）。

**解釈B（全額再投資）は方向性として筋が通っている。** 横ばい・下落局面では
レバ買い持ちを明確に上回る（2000-2020: +1.3% vs -6.3%、
リーマン含む3年: -6.0% vs -37.1%）。利益確定によって継続保有時の
減衰を避けられる、という戦略の狙いどおりに機能している。

**ただし最大ドローダウンが72〜99%に達する。** 「年率14%」を主張するなら、
その過程でどれだけの含み損に耐える必要があるかとセットで示す必要がある。
Bの成績が良い期間ほどDDも深い（1949-1990年はMOIC3,900倍だがDD 72.8%、
全期間70年はMOIC71倍だがDD 99.1%）。

### 5. 「年率14%以上」の実績は、今日の投資家には再現しにくい

Bの解釈で年率14%を超えたのは1949-1990年（+22.7%）だけ。
2000年以降のどの区切りでも年率+1.3%〜+3.9%に留まり、
セミナーの主張する水準には遠く及ばない。
