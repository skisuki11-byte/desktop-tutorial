# 出納管理アプリ（公開版）

手書きの出納帳をExcel化し、科目別・月別の集計、カメラでの追記、
収支報告書の作成ができるアプリです。

**このリポジトリに帳簿の中身は入っていません。** アプリだけを置いています。

## 使い方

1. ページを開く
2. 「設定」タブ →「JSONを取り込む」で、自分のバックアップを読み込む
3. 以降はその端末の中にデータが保存されます（サーバーには何も送りません）

スマホなら「ホーム画面に追加」でアプリとして使えます。追加後はオフラインでも動きます。

## Googleドライブとのやりとりについて

「設定 → 置き場所から反映する」にGoogleドライブの配信URLを登録すると、
帳簿の読み書きができます。手順は `tools/drive-webapp.gs` に書いてあります。

- **読む**…「最新を反映する」を押したときだけ読みに行き、帳簿を置き換えます
- **書く**…編集するたび自動でドライブへ保存します（切ることもできます）。
  上書きせず日時つきの新しいファイルとして残るので、前の状態に戻せます
- どちらも管理者モードのときだけ動きます
- URLは端末のブラウザにのみ保存され、**このリポジトリには入りません**
- **URLを知っている人は帳簿を読むことも書き換えることもできます。**
  会計担当だけが持ち、他の方には渡さないでください

## カメラでの読み取りについて

「設定」タブに Anthropic の APIキー を登録すると、ノートを撮影して
AIに行を読み取らせ、内容を確認してから出納帳に追記できます。

- APIキーはブラウザ（localStorage）にのみ保存され、送信先は `api.anthropic.com` だけです
- **APIキーをこのリポジトリに書き込まないでください**
- 共用のパソコンでは登録しないでください
