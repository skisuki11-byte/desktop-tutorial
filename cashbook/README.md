# 出納管理アプリ（公開版）

手書きの出納帳をExcel化し、科目別・月別の集計、カメラでの追記、
収支報告書の作成ができるアプリです。

**このリポジトリに帳簿の中身は入っていません。** アプリだけを置いています。

## 使い方

1. ページを開く
2. 「設定」タブ →「JSONを取り込む」で、自分のバックアップを読み込む
3. 以降はその端末の中にデータが保存されます（サーバーには何も送りません）

スマホなら「ホーム画面に追加」でアプリとして使えます。追加後はオフラインでも動きます。

## Googleドライブとのやりとりについて

「設定 → 置き場所から反映する」にGoogleドライブの配信URLを登録すると、
帳簿の読み書きができます。手順は `tools/drive-webapp.gs` に書いてあります。

- **読む**…「最新を反映する」を押したときだけ読みに行き、帳簿を置き換えます
- **書く**…編集するたび自動でドライブへ保存します（切ることもできます）。
  上書きせず日時つきの新しいファイルとして残るので、前の状態に戻せます
- どちらも管理者モードのときだけ動きます
- URLは端末のブラウザにのみ保存され、**このリポジトリには入りません**
- **URLを知っている人は帳簿を読むことも書き換えることもできます。**
  会計担当だけが持ち、他の方には渡さないでください

## カメラでの読み取りについて

読み取りは2通りあります。どちらも、確認用の表で直してから出納帳に追記します。

### ① 無料の読み取り（APIキー不要・既定）

撮影した写真を、**この端末の中だけ**で文字にして表にします（Tesseract.js を
`vendor/tesseract/` に同梱。写真も文字も外部へは送られません）。

- 初回だけ、部品と日本語データ（約6MB）を読み込むので1分ほどかかります
- **手書きの日本語は誤読が多い**です。印刷された領収書やきれいな字なら実用的です。
  表で金額・科目を確かめてから追記してください（残高が合わない行は「要確認」）
- 読み取った文字は「文字で取り込む」欄に入るので、直して「表にする」を押し直せます
- スマホの文字認識（iPhoneのテキスト認識表示／Googleレンズ）でコピーした文字を、
  この欄に貼り付けても取り込めます。1行を「日付 科目 摘要 金額 残高」の順に並べます
- 同梱ファイルのライセンスは `vendor/tesseract/LICENSE-*.txt`（Apache-2.0）。
  日本語データは `@tesseract.js-data/jpn`（4.0.0_best_int）です

### ② AIでの読み取り（APIキーが要る・従量課金）

「設定」タブに Anthropic の APIキー を登録すると、ノートを撮影して
AIに行を読み取らせ、内容を確認してから出納帳に追記できます。手書きに強いです。

- APIキーはブラウザ（localStorage）にのみ保存され、送信先は `api.anthropic.com` だけです
- **APIキーをこのリポジトリに書き込まないでください**
- 共用のパソコンでは登録しないでください
