# 高配当ポートフォリオ管理

米国高配当株を**PayPay証券で毎月10万円積み立てる**計画を、
配分・入金カレンダー・将来試算とあわせて管理するアプリです。

計画のもとはNotion「高配当ポートフォリオ設計（PayPay証券・2026年8月）」ですが、
**VICIがPayPay証券で買えなかったため構成を組み替えています**（下記）。

| 銘柄 | 配分 | 利回り | セクター | 入金月 |
|---|---|---|---|---|
| MO アルトリア | 25% | 6.20% | タバコ | 1・4・7・10 |
| VZ ベライゾン | 25% | 6.00% | 通信 | 2・5・8・11 |
| BTI ブリティッシュ・アメリカン・タバコ | 10% | 5.60% | タバコ（英ADR） | 2・5・8・11 |
| OKE ONEOK | 10% | 4.80% | エネルギー | 2・5・8・11 |
| PFE ファイザー | 20% | 6.40% | 医薬 | 3・6・9・12 |
| CPB キャンベルズ | 10% | 7.10% | 食品 | 1・4・8・11 |
| **合計** | **100%** | **6.08%** | 5セクター | 12か月すべてに入金 |

NISA成長投資枠での手取りは5.53%（BTIは米国源泉税がかからないため、表面利回りの割に手取りが良い）。

## 使い方

`index.html` をブラウザで開くだけ。インストール・ビルド・通信は一切不要で、
スマホでもオフラインで動きます。入力内容は端末内（localStorage）に保存されます。

1. **保有** タブで、PayPay証券アプリに出ている評価額をそのまま入れる
2. **今月の積立** タブに出た金額を、PayPay証券のつみたて設定に入れる
3. 約定したら「この内容で買ったと記録する」を押す（取得額と評価額に足されます）

**買付はPayPay証券アプリで行います。** このアプリは記録と試算だけで、
証券会社との連携機能はありません（2026年8月時点でPayPay証券に外部連携の提供が無いため）。

## 画面

| タブ | できること |
|---|---|
| ホーム | 評価額・年間配当（手取り）・取得利回り。運用ルール違反の自動チェック |
| 保有 | 銘柄ごとの評価額／取得額の入力。含み損益・YoC・採用理由とリスク |
| 今月の積立 | **売らずに買い増しだけで目標配分へ寄せる金額**を算出。コスト内訳と買付記録 |
| 入金カレンダー | 12か月ぶんの入金予定（月別の積み上げグラフ） |
| 試算 | 5年シミュレーション、株価シナリオ別、減配ケース、買い方によるコスト差 |
| 確認事項 | PayPay証券で確かめることのチェックリスト（下記） |
| 設定 | 積立額・口座区分・買い方・前提の変更。銘柄の差し替え。書き出し／取り込み |

## PayPay証券で確認したこと（2026年8月12日時点）

Notionの「未確認・要確認事項」を調べた結果です。詳細は
[`docs/PayPay証券-確認結果.md`](docs/PayPay証券-確認結果.md) にあります。

### 計画と食い違っていた点

**1. つみたてロボ貯蓄はNISA口座で取引できない。**
PayPay証券は「つみたてロボ貯蓄アプリでのお取引は特定口座（源泉徴収あり）のため、
NISA口座でお取引いただくことはできません」と明記しています。
米国株の自動積立でまず名前が挙がるアプリですが、これを使うと特定口座になり、
手取りは 5.75% → 4.58%、残高750万円なら**年間で約9万円の差**です。

**2. つみたて（自動買付）のスプレッドは0.7%固定。** 計画が前提にしていた0.5%は、
立会時間内に自分で発注したときの値です。つみたてロボ貯蓄は米国市場が開く日の
日本時間0時以降に約定し、スプレッドは一律0.70%。
買付コストは 0.7% + 為替0.23% = **約0.93%** になります（計画は0.73%前提）。
5年間の残高への影響は約1.7万円。

この2つを合わせると、**NISAで積み立てたいなら月1回の手動発注が有力**です
（NISAが使えてスプレッドも0.5%に下がる）。

### 裏が取れた点

- 米国株のスプレッドは立会時間内0.5%／時間外0.7%、為替は1ドルあたり35銭 — 計画どおり
- NISA成長投資枠は制度として米国株の個別銘柄・ETFが対象（整理・監理銘柄を除く）
- MO・VZ・PFE・CPB の4銘柄はPayPay証券で取扱いがある（自社の配当利回りランキングに掲載）

**3. VICIは買えない。米国REITは全般に扱いが無いとみておく。**
米国REITは日本では「外国投資信託」の扱いで、銘柄ごとに金融庁への届出が必要です。
銘柄を絞っている証券会社では扱いが無いことが多く、O や SPG に替えても同じ結果になる公算が高い。
VICIはS&P500構成銘柄でもあったので、「S&P500に入っている＝買える」も成り立ちません。

### VICIの20%枠をどう埋めたか

Notionが挙げていた次点2つは、調べ直したらどちらも第9章の減配予兆に当てはまりました。

- **AMCR** … Berry Global合併で負債が膨張、GAAP配当性向175%。外部評価も持続不可能と指摘 → 除外
- **UPS** … 配当性向100%、FCF約55億ドルに対し配当支払い約54億ドル → 除外

代わりに **BTI 10% ＋ OKE 10%** を採用しました。

BTI（ブリティッシュ・アメリカン・タバコ）は英国籍のADRで、**米国源泉税10%がかかりません**。
NISAなら配当が完全に非課税で、表面5.60%がそのまま手取り5.60%。
同じ手取りを米国株で得るには表面6.22%が必要で、VICIの穴を税制で埋められる唯一の候補でした。
ただしMOとタバコで重なるため10%に留め、セクターが新しく増えるOKEと折半しています。
運用ルールに**「同じセクターの合計は40%まで」**を足し、超えたら警告が出るようにしてあります。

### アプリを開いて自分で確かめること

1. **銘柄ごとのNISA可否** — 取扱銘柄一覧に「NISA対象」の絞り込みがあり、**銘柄ごとに可否が違います**。
   「取扱いがある＝NISAで買える」ではありません。6銘柄すべてを1銘柄ずつ確認してください
2. **PayPay証券アプリのつみたて投資でNISAを選べるか** — 選べなければ手動発注に切り替え
3. **BTI・OKE の取扱い** — 差し替えた2銘柄は取扱いを確認できていません。
   BTIが無ければOKEを20%にするかUSB（取扱い確認済み・4.73%）で、OKEが無ければUSBで埋めます。
   設定タブから配分を保ったまま差し替えられます
4. **BTIの源泉徴収が実際に0か** — 初回の配当入金時に取引報告書で確認してください

確認事項タブに、銘柄ごとの取扱い状況の一覧とチェック欄を用意してあります。

## 計算について

計算エンジンはNotion掲載時の構成（VICI入り）で検証し、5年後の残高・年間配当・
株価シナリオ別・減配ケースのすべてが誤差3%以内で一致することを確認しています。
銘柄を差し替えたあとも同じ式で計算しています。

- **手取り** … NISAでも米国源泉10%は必ず引かれます（租税条約の税率で、これは避けられない）。
  特定口座はさらに国内20.315%。ただしBTIは英国籍ADRなので米国源泉が0で、銘柄ごとに税率を持たせています
- **今月の買付額** … 目標配分に足りていない銘柄から順に埋めます（売却はしない）。
  NISA枠は売ると翌年まで戻らないため、リバランスは買い増しだけで行う方針です
- **減配ケース** … 減配が「いつ起きるか」で痛み方が変わるので、5年目に起きた場合（配当が減るだけ）と
  初年度から続いた場合（再投資できる額も減る）の両方を出しています

## 注意

利回り・株価は2026年8月12日時点の公開データによる概算で、実際の値とはズレます。
このアプリは記録と試算のための道具であり、投資の助言ではありません。
