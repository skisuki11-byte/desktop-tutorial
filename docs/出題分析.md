## 3. 得点戦略：どこで差がつくか

### ① 英英定義（4月型 大問2A）— **単語帳で満点が取れる唯一の大問**

英語の定義文を読んで単語を選ぶ形式。**定義文自体が平易**で、単語の意味さえ知っていれば即答できる。
過去3回で問われた12語は全て高校標準レベル：

- R3-4: `embarrassing` / `accept` / `symbol` / `major`
- R4-4: `quick` / `competition` / `cooperate` / `enthusiasm`
- R5-4: `refuse` / `vehicle` / `curious` / `remotely`

**誤答選択肢が同じ接頭辞・似た綴りで揃えられる**のが特徴（competition/completion/corporation/contradiction、
cooperate/communicate/concentrate/correlate）。→ **綴りが似た語をセットで覚える**のが対策。

### ② 連語・イディオム（4月型 大問2B）— **暗記量が有限で費用対効果が最大**

過去3回の正解＋誤答選択肢＝**48個**のイディオム。誤答選択肢も次年度に正解として出る可能性が高い。

正解：`when it comes to` / `take place` / `hand in` / `on behalf of` / `bring up` / `hang on` /
`in case of` / `pay off` / `for free` / `in addition to` / `by chance` / `turn in`

**句動詞（take/bring/hand/turn/pay + 副詞）と前置詞句（in 〜 of）の2系統**に整理できる。

### ③ 長文の空所補充（9月型 大問4）— **9問＝配点最大の語彙問題**

長文中の空所に語を入れる形式だが、実質は**語彙力テスト**。過去4回で正解になった語：

- R2-9: while / maintain / different / what / expressed / characteristic / supports / percentage / preserving
- R3-9: limit / especially / opportunities / increased / what / environmental / required / density / unless
- R4-9: advantage / less / While / remove / indeed / describe / reveals / among / choice
- R5-9: every / because of / by comparison / farther / While / surprising / estimated / imported / construction / development

**接続詞・接続表現（while / unless / because of / by comparison / in other words）が毎回1〜2問**出る。
これは意味を知っていれば文脈から即決できる。**最優先で覚えるべき領域**。

### ④ 文法・語法（4月型 大問3／9月型 大問2A）— **論点が完全に固定**

7回分で問われた論点はほぼ以下に集約される：

| 論点 | 出題例 |
|---|---|
| 付帯状況 `with + O + 分詞/形容詞` | with his arms crossed / with his legs crossed（**2回**） |
| 知覚動詞 + O + 原形 | saw a woman **cross** the street |
| have + O + 過去分詞 | had her blood **taken** |
| 形式目的語 it | found **it** difficult to〜 |
| 強調構文 It is 〜 that/who | Was **it** your little brother who〜 |
| 仮定法倒置 | **Had I known** that〜 |
| 完了形（大過去） | I **had forgotten** my wallet |
| 不定詞の完了形 | is said **to have been** born |
| 関係副詞 when / 関係代名詞 which | The time **when**〜 / **which** places |
| 代名詞 that（不可算の反復） | like **that** found in forests |
| 自動詞 vs 他動詞 | want to **talk** about（discuss/mention は about 不要） |
| 分詞の後置修飾 | an article **written** in French / children **playing** |
| 結果の不定詞 only to〜 | arrived **only** to find |

→ **13論点を潰せば文法は満点圏**。

### ⑤ 長文の頻出テーマ

社会・科学系の説明文が中心で、テーマは繰り返される：

- 統計・調査（結婚観／海外居住意識／メディア信頼度／コロナ後の高校生意識）
- テクノロジー（AI／チェスとDeep Blue／DeLorean）
- 環境・社会問題（プラスチックごみ／食料自給率／最低賃金／ガラスの天井／Xジェンダー）
- 生物・科学（睡眠／ナマケモノ／チーター／感情と表情）

→ `survey / percentage / participant / reveal / indicate / figure / decrease / majority` など
**統計を語る語彙**が全年度で繰り返し出る。

## 4. アプリの設計方針（この分析の反映）

1. **英英定義モード** … 過去問12問＋同形式の類題。定義文→単語の一問一答。
2. **連語・熟語モード** … 過去問の正解＋誤答選択肢48個を全て収録。
3. **文法・語法モード** … 上記13論点を一問一答化。
4. **長文空所語モード** … 大問4の正解語＋誤答選択肢（＝約140語）を収録。誤答選択肢の意味も表示。
5. **統計・長文頻出語モード** … 長文本文から抽出した必修語。

いずれも**出典（令和◯年◯月 問◯）付き**で、実際に出た語かどうかが分かるようにする。
