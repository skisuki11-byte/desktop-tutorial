# 人を集める（バズり対策）

2026-10-19 作成。ゲームの中で できることは 実装ずみ。のこりは 公開後に 自分で やること。

## 参考にした事例
- 成功: Grow a Garden（2025）— 種屋の入荷・天気が「全サーバーで同じ時刻」。「いま ◯◯が来てる！」と 学校やSNSで 話題になり、決まった時刻に 人が集まった
- 成功: Adopt Me! — 週ごとの アップデートと 期間イベントで「また来る理由」を 作り続けた
- 失敗: 中身と ちがう サムネイル・「もうすぐ消える！」の せかす売り方 — 一度は 押されても すぐ やめられ、おすすめの 数字が 悪くなる

## ゲームの中で やったこと（2026-10-19）
- **キャンディラッシュ**: 世界時の 0時から 3時間ごとに 15分（日本 9・12・15・18・21時）。売値+50%・きらきら+20%・めずらしい種が かならず 入荷。5分前と はじまりに お知らせ、画面の下に「つぎは 21:00」
- **遊んだ段の記録**: クリエイターハブ → 解析 → ファネル（Joined → Planted → Harvested → Sold → BoughtSeed → HatchedEgg → BuiltBase）。ラッシュに来た人は カスタムイベント `RushJoined`
- **10言語** と クリエイターハブの 名前・説明文の 翻訳

## 公開後に 自分で やること（効く順）
1. **サムネイル**: レアなペット（ゆめのフェニックス・スターケーキドラゴン）を 大きく。1枚目は「ペットと 実った畑」。文字は 少なく（スマホで 小さく見えるため）
2. **少しだけ 広告**（Robloxの 広告マネージャー）: 1日 数百Robux から。下の 数字を 見て、良ければ 続ける
3. **ラッシュの 時刻に 合わせて 告知**: アップデートや コードの お知らせは ラッシュの 少し前に
4. **小さな 実況者に 紹介してもらう**: Roblox の 子ども向け 実況者に コード（`Codes.luau` に 足す）を わたす

## 見る数字（広告・紹介の あと）
| 数字 | どこで見る | 目安 |
|---|---|---|
| ファネルの Planted → Sold まで 進んだ割合 | 解析 → ファネル | 7割以上（下がる段が あれば そこの 案内を 直す） |
| 1回あたりの 遊んだ時間 | 解析 → エンゲージメント | 10分以上 |
| 次の日も 来た人（D1 リテンション） | 解析 → リテンション | 15%以上 |
| ラッシュの時間の 同時接続 | 解析 → 同時接続 | ラッシュ中に 山が できるか |
