## いちばん大事な決まり（Roblox の公式ルールから）

- **ガチャをお金で買わせない。** Roblox では、ロバックスで直接、または「ロバックスで買えるゲーム内のお金」で間接に、中身がランダムな物を買えると「有料ランダムアイテム」になる。確率の表示、年齢・国ごとの制限（`ArePaidRandomItemsRestricted`）への対応が必要になり、アンケートの答えも重くなる。
  - このゲームの たまご は コインで買える ランダムな物。だから **コインを ロバックスで売らない**（間接に売るのもダメ）。
- **お金で買った物を交換させない。** ペットは交換（トレード）できる。ロバックスで手に入れたペットや物が交換できると「有料アイテムの交換」になり、`IsPaidItemTradingAllowed` への対応が必要になる。
  - だから **ロバックスで ペットを渡さない**。売るのは 交換できない物（見た目・家具・便利さ）だけ。
- 出典: [有料ランダムアイテムの方針](https://create.roblox.com/docs/production/monetization/paid-random-items)・[公式の補足（DevForum）](https://devforum.roblox.com/t/clarifying-requirements-for-paid-random-items/4654622)・[アンケートの項目](https://create.roblox.com/docs/production/promotion/content-maturity)

## 参考にした事例

- 成功: **Adopt Me!** — 売れ筋は見た目と便利さ（乗り物・家・ペットの見た目）。遊びの中心（ペットを育てる）は無料で全部できる → 子どもと親の信頼が続く
- 成功: **あつまれ どうぶつの森** — 家と家具が「自分だけの ごほうび」。このゲームの ひみつきち と同じ考え。見た目の物は、遊びのバランスを こわさずに売れる
- 失敗: **ルートボックス（ガチャ）規制** — ベルギー・オランダは 有料ガチャを禁止、イギリスは Roblox が18歳未満に制限。日本では 2012年に「コンプガチャ」が景品表示法で禁止。→ ガチャで稼ぐ形は、子ども向けでは 続かない
- 失敗: **Pet Simulator 系の「倍率パスの重ね売り」** — 2倍・3倍・幸運などを たくさん売ると、無料の子が 置いていかれ、「お金を出さないと遊べない」と言われる
- 失敗: **せかす売り方**（「あと5分で消える！」の くり返し） — 子どもを あせらせる売り方は、親の信頼を失い、Roblox の決まり（子どもを だます見せ方の禁止）にも ふれやすい

## 売らない物

- コイン・種・たまご・ペット（→ 有料ガチャ・有料アイテム交換になる）
- 「すぐ育つ」を1回ずつ売る物（子どもが 何回も押して 使いすぎる）
- 売値やコインの倍率（→ 下の「なおすところ」）
- 広告（子ども向けでは 使える形が かぎられる）

## いまのコードで なおすところ（作るときに いっしょに）

1. **うりね2ばいパス（coins2x）をやめる** — ロバックスでコインの入り方を2倍にすると「お金で コインを買う」に近くなる。コインで たまご（ランダム）が買えるので、さけたほうが安全。かわりに「おおきな じょうろ」
2. **キャンディパス スペシャルの ごほうびから コインと種を なくす** — いまは スペシャルの道に コイン（最大1,500）と種が入っている。おしゃれ・家具・かざり・ひみつきちの見た目に入れかえる
3. ショップの「スペシャル」の画面に「おうちの人に きいてから 買おうね」を出す。押しまちがいを防ぐため、買うボタンは 2回押し（いまの高い買い物と同じ）

## アンケート（Maturity & Compliance）の答え（案）

Roblox Kids（5〜8さい）と Select（9〜15さい）に出すには、**ぜんぶの質問に答える**必要がある。いまのゲームの中身で答えると:

| 項目 | 答え | 理由 |
|---|---|---|
| 暴力 | なし | たたかい・武器なし |
| 血 | なし | |
| こわい物 | なし | しょんぼり雲は「悲しい顔の雲」で、こわがらせる物ではない |
| 下品な笑い | なし | |
| 遊べないギャンブル | なし | たまごは コインで買う（ロバックスでは買えない） |
| 強い言葉 | なし | チャットは Roblox の フィルターのまま |
| 恋愛 | なし | ひみつきちは 自分ひとりだけ（友だちも入れない） |
| お酒 | なし | |
| 社交の場が中心 | いいえ | 中心は 畑・ペット。ひみつきちは ひとりだけの へや |
| 自由に描く・書く物 | なし | 名前を入れる場所なし。ログインコードは 決まった言葉だけ |
| 社会・政治・宗教 | なし | |
| 有料ランダムアイテム | なし | 上の決まりを守るかぎり |
| 有料アイテムの交換 | なし | ロバックスの物は 交換できない形にするかぎり |
| 画像・動画の共有 | なし | |
| 生成AIとの会話 | なし | |

→ 予想ラベル: **Minimal（いちばん やさしい）**。上の「売らない物」を守れば、課金を入れても 答えは変わらない。

注意: Kids・Select に出すには、ほかに「16さい以上の年齢確認ずみの人で 60日に 250回の しっかりした プレイ」「作者の年齢確認と 2段階認証」などの条件がある（[Roblox Kids and Select](https://create.roblox.com/docs/production/publishing/kids-and-select)）。
