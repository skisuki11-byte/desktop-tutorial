# 公開の準備

今は**非公開**（自分とテスターだけ）。この紙は「みんなに公開する前」にやることのまとめ。

## 参考にした事例

- 成功: Grow a Garden（2025）。アイコンは「大きく1つの絵＋はっきりした色」で、小さく表示されても何のゲームか分かる。説明文は短く、最初の行で遊び方が分かる
- 成功: Adopt Me!。説明文の最初に「何ができるか」、その下にアップデート情報。新しいことが分かると、また来てくれる
- 失敗: 中身と違うサムネイル（実際に無い景色・キャラ）は Roblox の規約で「誤解を招く広告」とされ、差し替えや処分の対象になる。→ 画像は**実際のゲーム画面から作る**
- 失敗: 説明文にキーワードを並べるだけ（「pet sim garden grow simulator…」）は、読みにくく、規約でもスパム扱いされうる

## アイコン・サムネイル（案）

いずれも**ゲームの中で撮った画面**をもとに作る（中身と違う絵にしない）。
- アイコン（512×512）: 実った作物（いちごグミ）とグミベアのペットを大きく1つずつ。背景はピンクの空。文字は入れない（小さいと読めないため）
- サムネイル1（1920×1080）: 庭の全体。木の床・白い柵・実った畑・キラキラ
- サムネイル2: みんなの木のレベルアップの瞬間（光る飾り・紙ふぶき）
- サムネイル3: ペットのたまごが割れる場面
- 撮り方: ボタンなどの画面（UI）は Play 中だけ出るので、UI の無い絵は Studio の編集画面で撮る（Play で一度遊んで畑を実らせた状態を見せたいときは、Play 中に Windows の Snipping Tool で撮る）

## 16歳未満にも遊んでもらう（クリエイターハブ → オーディエンスを管理）

前提: 16歳未満に公開する。2026-10-20 時点の状態。
- [x] 本人確認（政府発行の書類）
- [x] コンテンツレーティングの確認（「極少（Minimal）」）
- [x] 2段階認証をオンにする（2026-10-20。オンにすると Studio のログインが切れるので、ログインし直す）
- [x] 手数料 1,000 Robux を払う（2026-10-20 に 支払いずみ。ゲームごとに 1回だけ。90日ほどで 自動で 返金される）
- [ ] 審査: 16歳以上の 年齢確認ずみで よく遊ぶプレイヤーが 60日の あいだに 250人 遊ぶ（**一般公開してから**数える）。急ぐなら 50,000 Robux（返金あり）で 早める審査もある

ゲームの中は、16歳未満向けのルールに合わせてある（2026-10-20 に確認）。
- お金で ランダムなもの（たまご・ガチャ）を 売らない → `PolicyService` の「有料ランダムアイテム」制限に当たらない
- Robux で買ったものは 交換できない（交換は 無料で手に入れた ペットだけ・友だちどうしだけ）→「有料アイテムの取引」に当たらない
- 外のサイト（YouTube・Discord など）への 案内を 出さない
- 自由に文字を書いて ほかの人に見せる所がない（コード入力と 図鑑の検索は 自分の画面だけ）。名前は Roblox の 表示名だけ
- 自由に組み立てて見せる 作品づくりがない（ひみつきちの家具は 決まったものを 置くだけで、本人しか入れない）
