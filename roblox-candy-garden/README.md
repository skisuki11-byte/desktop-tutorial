# キャンディガーデン（仮）

お菓子の庭で、みんなで育てる協力型のRobloxゲーム。方針は [HANDOFF.md](HANDOFF.md)、環境は [SETUP-STATUS.md](SETUP-STATUS.md) を参照。

## 動かし方

1. Studioで空のPlace（Baseplate）を開く。
2. このフォルダで `rojo serve` を実行する。
3. StudioのプラグインタブでRojoを開き、**Connect**を押す。
4. ▶ Play（またはF5）。

マップ・植物・UIは全てコードで生成する（素材は使わない）。

## 構成

- `src/ReplicatedStorage/Shared/` Config（作物の数値）, Remotes, I18n（日本語/英語）
- `src/ServerScriptService/` Main と Services（Data, World, Garden, Shop, RateLimit）
- `src/StarterPlayer/StarterPlayerScripts/Client/` UI, Tutorial, Style

## 実装済み（縦のスライス）

区画 → 種を植える → 育つ → 収穫 → 売る → コイン表示 → 保存、初回チュートリアル。
ペット（Pals）: たまごを買う（確率を表示）→ 孵化演出 → 最大3匹を連れ歩く → 売値ボーナス。
お天気: 最初は起動60秒後、以後は約5分ごとに90秒、きらきら確率が上がる。お知らせ・残り時間チップ・降る粒子つき。
コミュニティの木: サーバー全員の収穫が成長ポイントになる協力要素。レベルが上がると、サーバーにいる全員にコインを配り、木が大きく飾りが増える。奪い合いの代わりの仕組み。進み具合は全サーバー共通で、サーバーが閉じても残る（MemoryStore に10秒ごとに足し、1分ごとに DataStore `CandyTree` へ控え。Studio は `CandyTree_Studio`）。
  見た目: レベル10までは毎回なにかが増える（2 飾りが光る / 3 星 / 4 花のわ / 5 キャンディケーン / 6 葉っぱ二段 / 7 ちょうちん / 8 いつもキラキラ / 9 浮かぶペロペロキャンディ / 10 金の冠）。
  色はレベル10で「金色の夕焼け」、レベル20で「星空」に変わる（`Config.Tree.Themes`）。横より縦に伸ばして、スマホの縦持ちでも収まるようにしている。
  必要ポイントの増え方は1.25倍（レベル20まで合計 約6,800ポイント）
おしゃれ（アバターアイテム）: ぼうし7・せなか5・トレイル3。全てコードで作った見た目で、コインで買える（無料の道）。最初にうさみみをプレゼント。
見た目: 子供が触りやすい作り（太い縁取り、丸いフォント、64px前後の大きなボタン、下の中央にドック）。Robloxの移動スティックとジャンプボタンの場所を避けて配置。
デイリーボーナス: 1日1回、ログインでもらえる。7日で一巡（種のおまけつき）。受け取れるときは自動で開く（初めての人のチュートリアル中は開かない）。休んだら連続日数が半分になって再開（0には戻さない）。日付はサーバーのUTC。
未実装: 本番のゲームパスID設定（上の「収益化」参照）、シーズンパス、期間限定ショップ。

## キャンディパス（シーズンパス）

右の列の「🎫 パス」から開く。収穫・デイリーボーナス・みんなの木のレベルアップでXPがたまり、20段まで。
- 段に届いたら自動で受け取る（押し忘れで損をしない）。参加したときにも、取りこぼしをまとめて渡す
- 無料の道: コイン・種・限定のおしゃれ（10段目いちごぼうし／20段目ペロペロキャンディ）
- スペシャルの道: `Config.Passes.season` にゲームパスのIDを入れると出る。中身は決まっている（ランダム無し）。あとから買っても、届いた段のぶんはさかのぼって渡す
- 段・ごほうび・XPの量・終わる日時は `Config.Season`。新しいシーズンは `id` を変えると、XPと受け取り状況がリセットされる
- 参考: Grow a Garden のシーズンパス（50段・無料と有料の2本立て。第三者の記事）を、子供向けに20段へ小さくした

## 期間限定ショップ（日替わり）

ショップのいちばん上に「⏰ きょうの とくべつ」。毎日 UTC 0時（日本時間 朝9時）に3品が入れ替わる。
- 品物は `Config.LimitedShop.pool`（限定おしゃれ4つ＋お得な種セット4つ）。並びは日付だけで決まる（サーバーとクライアントで同じ）
- コインだけで買える。1日1枠1回まで。品物は何日かすると戻ってくる（画面にも「また そのうち もどってくるよ」）
- 参考: Grow a Garden の期間限定の商人、日替わりのアイテムショップ。子供を「今だけ」で焦らせないよう、ロバックスは使わない

## 見た目の方針「かわいい形 × リアルな光と質感」

写実（リアル一辺倒）にはしない。形と色はかわいく、光・影・空・草・水・木目などの質感だけリアルにする。
- お手本: あつまれ どうぶつの森（かわいい形のまま、光と質感をリアルにした）。逆に、かわいいものを写実にして反発を受けた例に映画ソニック（2019年の予告編のあと作り直し）
- 地形: 遊ぶ範囲は短い芝（長い草だと畑や飾りが埋もれる）、遠くの丘と野原だけふさふさの草。いちごミルクの池
- 地形の高さの注意: ぎっしり埋めたブロックの表面は2stud上に描かれる。いちばん上の一段を「半分埋め」にして表面を y=0 にそろえている（`World.luau` の buildTerrain）
- 空: 立体の雲（Clouds）、ピンクにかすむ空気（Atmosphere）
- 畑: 木目の床、木枠の土、白い柵。作物は 芽→成長→実り（キラキラ）の3段階で、作物ごとに形が違う（`CropModels.luau`）
- 質感: 飴・グミはつやつや（ガラス）、わたあめは布のふわふわ、幹は木目
- 光の方式（Lighting.Technology）はスクリプトから変えられない。今の設定のままで影は出ている。Future にすると光がさらにリアルになるが、スマホが重くなるので、変える場合は Studio のプロパティで、スマホで確かめながら

## 翌日また来る理由

「明日、何が待っているか」を見えるようにする仕組み。
- 🌙 ムーンキャンディ: 8時間で育つ作物。寝る前に植えて、翌日に大きな売値で収穫（オフライン中も育つ）
- 🌅 おかえりメッセージ: 10分以上たって戻ると「いない間に ○こ 実ったよ」（`Config.WelcomeBackSeconds`）
- 📋 きょうのおねがい: 毎日3つの小さな目標（`Config.Quests`）。達成で「もらう！」→コイン＋パスXP。「あしたも あたらしい おねがいが くるよ（あと○）」を常に表示
- 🔮 あしたの予告: デイリーボーナスを受け取ったあと、あしたのごほうびを「あしたは これ！」と光らせる
- ほかに: デイリーボーナスの連続記録、日替わりの期間限定ショップ、キャンディパス

画面の配置: 移動ボタン（じぶんの庭・みんなの木）は上のまん中（Grow a Garden 2 と同じ）。右の列は パス・おねがい・ボーナス・コード の4つ。

## 効果音とBGM

`Client/Sounds.luau`。権利のはっきりした無料素材だけを使う（ほかのゲームから取った音は使わない）。
- 効果音: Daily Sounds（DailySoundsFX が自分で合成した無料の効果音）の Tiny Click / Cartoon Pop / Coin Pickup。音の高さを変えて使い分ける（植える＝低いポン、収穫＝高いポン、売る＝コイン、買う＝低いコイン、できない＝やさしいブブッ）
- お祝いの和音（ド・ミ・ソ・ド）は、コインの音の高さを変えて重ねて作る。たまご・みんなの木・パスの段・デイリー・コード成功で鳴る
- BGM: Sweet Kitchen（DistrokidOfficial）。音量は小さめ。左の列の🎵ボタンでオン/オフでき、設定は保存される

## 画面の配置（操作のしやすさ）

人間工学の考え方（よく使う物ほど大きく近くに・選ぶ物は少なく・使わない物はしまう）で整理した。
- 画面の下（畑と足元）には何も置かない。種えらびは上のまん中（空のあたり）
- いつも出すのは、毎回使う物だけ: コイン・種・ショップ／収穫／売る・庭と木への移動
- あまり使わない物（ペット・おしゃれ・パス・おねがい・ボーナス・コード・おんがく）は「メニュー」にしまう。受け取れる物があるとメニューに「!」
- お天気の表示はお天気の間だけ、みんなの木の表示は木の近くにいるときと進んだ直後だけ出す
- パソコン: 左の列に [コイン][メニュー]、その下にショップ・収穫・売る。左上のRobloxのチャット欄の下から始める
- スマホ: ショップ・収穫・売るは右手の親指が届くジャンプボタンの上。左下は移動スティック専用（いつも見える固定のスティック）
- スマホ縦持ち: 1段目 [コイン][メニュー] … [🏡][🌳] / 2段目 [種えらび] … [みんなの木のレベル] / 3段目 お天気（お天気のときだけ）
- スマホ横持ち: 1段目 [コイン][メニュー] … [種えらび] … [レベル][🏡][🌳] / 2段目 お天気。右側の縦はショップ・収穫・売る（ジャンプボタンの上）
- スマホのメニューは三本線だけ（小さいボタンに文字を入れると見切れる）。大きさは画面の短い辺に合わせ、回すと並べ直す
- 文字が枠に入らないときは、自動で小さくする（`Style.fitText`。狭い画面でも見切れない）
- Studioで配置を試すとき: CandyUI の属性 `ForceLayout` に "pc" / "phone"（縦持ちを試すときは `ForcePortrait` = true）
- 畑の「植える・収穫」は、Robloxの大きな吹き出しの代わりに、畑の上の小さな丸いボタン（`PromptUI.luau`）。キーボードは E
- 庭の名札・みんなの木の看板は stud 単位の大きさ（遠くでは小さく見え、近くでも画面をふさがない）
- 十字キーは使わない: Robloxの標準はスティックで、斜めにもなめらかに動ける。子供が慣れている標準の操作に合わせ、見つけやすいよう固定表示にした

## 朝・昼・夕方・夜の空

遊んでいる人の本当の時刻に合わせて、空が変わる（`Client/DayNight.luau`。あつまれ どうぶつの森と同じ考え方）。
朝は朝焼け、夕方は夕焼け、夜は月夜。夜も畑や作物が見分けられる明るさにしている。
各自の画面だけで変えるので、住んでいる国が違ってもその人の時刻になる。Studioで試すときは LocalPlayer の属性 `ForceHour`（0〜24）。

## ログインコード

右の列の「🎟️ コード」から入力する。大文字/小文字・空白・ハイフンの違いは気にしない（子供の打ち間違い対策）。
1分間に5回まちがえると、少し待ってもらう（総当たり対策）。1人1回まで。

コードの追加: `src/ServerScriptService/Services/Codes.luau` の `CODES` に書く（サーバー専用。クライアントからは見えない）。
- キーは「大文字・空白なし」（例 `SWEETGARDEN`）
- `reward` に `coins` / `seeds` / `cosmetic`（コード限定のおしゃれ）
- `expiresAt` を入れると期限つき（UTCのUnix秒。`DateTime.fromUniversalTime(...)` で書ける）

今入っているコード（例・本番前に見直す）: `CANDY`（300コイン）, `SWEETGARDEN`（ペロペロの種3）, `RIBBON`（コード限定リボン）, `LAUNCH2026`（2026年末まで）。

## 画面の配置（売れているゲームを参考）

- 下の中央: 種えらび＋ドック（ショップ・ペット・おしゃれ・収穫・売る）
- 右の列: じぶんの庭／みんなの木へ移動（Grow a Garden 2 の移動ボタンと同じ考え方）、ボーナス、コード
- パネル: 色帯のタイトル＋右上の角の丸い閉じるボタン（全パネルで同じ位置）。開いている間はドックと右の列を隠す
- 影は公式の UIShadow で控えめに。「!」バッジは、受け取れるボーナスと、初めてのたまごが買えるときだけ

## 収益化（ロバックス）の設定

方針: 序盤に課金を迫らない／ランダム要素にロバックスを使わない（中身が決まった商品だけ）／全ての見た目はコインでも手に入る。
パスは `Config.Passes` の `id` が 0 の間は画面に出ない・買えない。作ったら、IDを入れるだけで有効になる。

1. create.roblox.com → 作品 → Candy Garden Test → 収益化 → ゲームパス で、2つ作る。
   - `coins2x`「売値2倍」（便利さ）
   - `gold`「ゴールドパック」（限定の見た目: ゴールドのつばさ）
2. 各パスのIDを `src/ReplicatedStorage/Shared/Config.luau` の `Config.Passes` に入れる。
3. 値段は、公開前に自分で決める（Grow a Garden系は149〜699ロバックス帯と言われるが、出典が弱いので参考まで）。
4. たまごなどのランダム要素を将来ロバックスで売る場合は、全ての確率を表示し、`PolicyService` で対象外の人への扱いを分ける（公式: Paid random items policy）。

## 開発メモ

- Rojoは**Play中は変更を取り込まない**。Playを止めてから同期を待ち、次のPlayを始める。
- `execute_luau` は実行中のゲームと別のモジュールのコピーを作る。ゲーム内の状態を見るときは、UIやAttributeなど実物を読む。

## ルール

- 乱数・お金・在庫は全てサーバーで管理。Remoteは全て型を検証し、回数を制限する。
- 保存はDataStore。Studioでは「Enable Studio Access to API Services」をオンにすると保存を試せる（オフでも遊べる）。
- Studioで遊んだデータは本番と別の保存場所（`CandyGardenV1_Studio`）に入る。本番は `CandyGardenV1`。Studioのテストで本番のデータが汚れない。
- 同時人数は `Config.MaxPlots`（8）。Studioの Game Settings → Max Players も8にする。
- 公開の準備（説明文・アイコン案・チェックリスト）は [PUBLISH.md](PUBLISH.md)。
