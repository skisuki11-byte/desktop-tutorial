キャンディガーデン　アイテム・ペット一覧

Roblox「キャンディガーデン（Candy Garden）」に出てくる ペット・たまご・作物・道具・おしゃれ・飾り・お天気・場所 のまとめです。
数字はゲームの設定ファイル（Config.luau）と同じ値です。名前は日本語／英語の両方をのせています。

🎨 イメージ作り（Codex など）へのお願い
  • 対象は小学生くらいの子供。やさしいパステル（ピンク・ラベンダー・水色・ミント・クリーム）と、おかしの質感（グミのつや、わたあめのふわふわ、キャンディのうずまき）。
  • 形は丸く、こわくないように。ドラゴンや鳥も「かわいい」寄り。目は大きく、ほっぺはピンク。
  • めずらしさは色の帯＋★の数＋名前の3つで見せる（色だけにたよらない）。★1 灰 → ★2 緑 → ★3 青 → ★4 むらさき → ★5 金 → ★6 星空の紺 → ★7 ゆめいろピンク。
  • 各項目の「色」は、ゲーム内で使っている基準色です。絵を作るときの主な色にしてください。
  • 文字はひらがな多め。漢字には ふりがな か、ひらがなで。

🧰 道具

道具は自分で選んで持ったときだけ使える（植えたあと自動では出ない）。ほかの人の畑にも使える。

なまえこうか入手メモ
💧じょうろ水やり（1回ごとに1つ減る）。育つ時間 −25%、きらきら +15%。ほかの人の畑に水やりすると お礼10コイン最初から持っている。ひろばの「いちごミルクのふんすい」で水をくむ（タダ）大きさ 3 / 4 / 5 / 6回分（どうぐ屋で 1,500 / 6,000 / 20,000コイン）
🌟キャンディひりょう育つ時間 −40%。ジャンボが出やすくなる（+10%）どうぐ屋 300コイン（最大99こ）つかいきり
🔮ふしぎのしずく実ったとき ふしぎな姿（ジャンボ・きんいろ・にじいろ）の確率が3倍どうぐ屋 1,500コイン（最大20こ）つかいきり

🗺️ 場所とお店

場所ようす
🌳みんなのひろば（まん中）大きな「みんなの木」。全員の収穫で育つ。たねやの屋台（ストライプの屋根）、いちごミルクのふんすい（じょうろの水くみ）、道しるべ
🌱たねや（ひろば）5分ごとに品ぞろえが入れかわる。どのサーバーでも同じ品ぞろえ、数は一人ずつ
🥚たまごの森（左のはし）わたあめの木にかこまれた広場に、白に水玉の大きな「たまごの家」。たまごはここだけで買える
🔧どうぐ屋（右のはし）木の小屋。屋根の上に大きなじょうろ。ひりょう・じょうろの大きさ・ふしぎのしずくはここだけ
🏡じぶんの庭（8人分）畑6マス→9→12マスに広げられる（30,000 / 150,000コイン）。まわりに飾りを6こ置ける

森の妖精 ルル Lulu, the forest fairy
はじめて遊ぶ人だけに出てくる案内役。会話カードの右上に少し重なって、ふわふわ浮かびながら話す。案内が終わると、くるっと回って空へ帰る。
