# AI秘書（LINE）

LINEのトークで話しかけるだけで、予定を入れて、用事を追いかけて、メモを残して、
調べものにも答える秘書です。サーバーは要りません。Googleアカウントの中だけで動きます。

```
あなた ──LINE──▶ Google Apps Script ──▶ Claude
                        │
                        ├─ Googleカレンダー（予定）
                        └─ スプレッドシート（用事・メモ・覚えたこと・会話）
```

## できること

| 送ると | こうなります |
|---|---|
| 「明日15時に歯医者」 | カレンダーに入れて「8/8(金) 15:00 歯医者 で入れました」と返す |
| 「今日の予定は？」「来週空いてる？」 | カレンダーを読んで答える |
| 「金曜までに請求書を出す」 | 用事として控え、**期限前と期限後に自分から催促する** |
| 「あれ終わったよ」 | 該当の用事を探して完了にする |
| 「これ控えといて」＋文章や**写真** | メモに残す。写真は中身を読み取って文字にする |
| 「A社の件どうだったっけ？」 | 残したメモを探して答える |
| 「〜について調べて」 | 答える（ウェブ検索は Claude に切り替えたときだけ。後述） |
| （毎朝7時） | その日の予定と、気になっている用事を送ってくる |

そして **話すほど覚えます**。「打合せは午前を避けたい」「山田さんはA社の担当」といった
次回以降も効くことを見つけたら記録し、次からの受け答えに反映します。

## 作り方

はじめから終わりまで、だいたい30分です。

### 1. LINEの窓口を作る

1. [LINE Developers](https://developers.line.biz/console/) にログイン
2. 「プロバイダー」を新規作成（名前は何でも可）
3. その中に **Messaging API** のチャネルを作成
4. **「Messaging API設定」タブ** を開く
   - 一番下の「チャネルアクセストークン（長期）」を **発行** してコピー → あとで使います
   - 「応答メッセージ」を **オフ**、「あいさつメッセージ」は好みで
5. 同じ画面のQRコードから、自分のLINEで **友だち追加** しておく

### 2. スクリプトを置く

1. [script.google.com](https://script.google.com/) →「新しいプロジェクト」
2. `src/` の中の `.gs` ファイルを、**1ファイルずつ同じ名前で**作って貼り付ける
   （左の「ファイル」＋ → スクリプト。`00_config` のように拡張子なしで入力）
3. ⚙「プロジェクトの設定」→「`appsscript.json` マニフェスト ファイルをエディタで表示する」に
   チェックを入れ、`appsscript.json` の中身を `src/appsscript.json` に差し替える

### 3. 鍵を入れる

⚙「プロジェクトの設定」→ 一番下の「スクリプト プロパティ」に3つ追加します。

| プロパティ | 値 |
|---|---|
| `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/apikey) で発行したAPIキー。**無料・カード登録も不要**です |
| `LINE_CHANNEL_ACCESS_TOKEN` | 手順1でコピーした長期アクセストークン |
| `WEBHOOK_TOKEN` | **自分で決めた合言葉**（例: `himitsu-8823`。推測されにくい文字列にしてください） |

### 4. 準備の関数を動かす

エディタ上部の関数リストから **`setup`** を選んで「実行」。

初回は「承認が必要です」と出ます。「詳細」→「（プロジェクト名）に移動」→「許可」。
*Googleが「安全でない」と警告しますが、これは自分で書いたスクリプトを自分で動かすときの
通常の表示です。* カレンダーとスプレッドシートに触る許可を与えます。

うまくいくと記録用のスプレッドシートが自動で作られ、朝のお知らせなどの仕掛けも入ります。

### 5. 公開してLINEとつなぐ

1. 右上「デプロイ」→「新しいデプロイ」→ ⚙ →「ウェブアプリ」
   - 次のユーザーとして実行： **自分**
   - アクセスできるユーザー： **全員**
2. 出てきた `https://script.google.com/macros/s/..../exec` をコピー
3. **末尾に `?token=（手順3の合言葉）` を足す**

   ```
   https://script.google.com/macros/s/AKfy..../exec?token=himitsu-8823
   ```

4. LINE Developers の「Messaging API設定」→ **Webhook URL** にこれを貼って更新
5. 「Webhookの利用」を **オン**

### 6. 話しかける

LINEで「こんにちは」と送ってみてください。返事が来たら完成です。

最初に話しかけた人が **持ち主** として記録され、以降その人以外には応答しません。

## 直したいとき

コードを貼り替えたあと、**「デプロイ」→「デプロイを管理」→ ✏️ → バージョン「新バージョン」→ デプロイ**
で反映します。URLは変わりません。

うまく動かないときは、エディタで **`status`** を実行してログを見てください。
設定の抜け、カレンダーの権限、仕掛けの有無がまとめて出ます。

| 症状 | 見るところ |
|---|---|
| 返事が来ない | `status` で `★未設定` がないか。Webhook URLの `?token=` を忘れていないか |
| 「この秘書は持ち主専用です」 | 別のLINEアカウントで話しかけている。スクリプト プロパティの `OWNER_USER_ID` を消すと再設定できます |
| 朝のお知らせが来ない | `testPush` を実行。届かなければアクセストークンを確認 |
| 頭脳でこける | `testBrain` を実行するとLINEを通さずに試せます |
| 「モデル名が違う」と出る | `listGeminiModels` を実行し、出てきた名前を `GEMINI_MODEL` に入れ直してください |
| 「無料枠の回数上限」と出る | 1分あたりの回数に当たっています。少し待てば戻ります |

## 育つ仕組み

「毎回成長していく」ところは、二段構えにしてあります。

**会話中** — 次回以降もずっと効くこと（好み・習慣・段取り・人の呼びかた）を見つけたら、
その場で `memory` シートに書き足します。一度きりの事実は覚えません。それは予定とメモの仕事です。

**毎晩23時** — その日の会話を読み返し、拾いこぼしを回収します。
古くなった項目は消します。会話の記録は600件を超えたら古い順に捨てます。

覚えたことは、次の会話から指示文に混ざります。中身はスプレッドシートの `memory` シートで
そのまま読めますし、手で直しても構いません。おかしなことを覚えていたら
「もうそれは違う」と伝えれば消します。

## やり通す仕組み

期限つきで控えた用事は、1時間おきに見張られています。

- 期限の60分前 … 「まもなく」と声をかける
- 期限を過ぎたら … 3時間おきに「期限切れ」と催促する
- 8回を超えたら … 「まだ必要ですか」と一度だけ聞いて、追いかけるのをやめる

しつこさは `00_config.gs` の `NUDGE_LEAD_MIN` / `NUDGE_INTERVAL_H` / `NUDGE_MAX` で変えられます。

## 費用

**すべて無料です。** カードの登録も要りません。

| | |
|---|---|
| Google Apps Script | 無料 |
| LINE Messaging API | 無料。返信は無料枠にカウントされません。数えられるのは*こちらから送る*分（朝のお知らせと催促で月30〜60通）だけなので、フリープランに収まります |
| Gemini API（頭脳） | **無料枠**。1日1,500回ほど使えるので、個人利用では余ります |

### ただし、無料の代償があります

**Geminiの無料枠は、送った内容がGoogleの製品改善に使われます。**
（Google自身が、有料枠へ上げる理由として「プロンプトと応答が製品改善に使われないようにするため」と
書いています）

この秘書が送るのは、予定の中身（人名・場所）、メモ・議事録、覚えた習慣です。
そこを承知の上でお使いください。避けたいときは次の二択になります。

- **Geminiに課金を有効にする** … 有料枠に上がると改善には使われなくなります
- **Claudeに切り替える** … 下記

### Claudeに切り替えるとき

スクリプト プロパティを2つ足すだけです。コードはそのままで、道具も記憶も催促も動きます。

| プロパティ | 値 |
|---|---|
| `PROVIDER` | `claude` |
| `ANTHROPIC_API_KEY` | [platform.claude.com](https://platform.claude.com/) で発行したキー |

既定は `claude-opus-5`（入力$5 / 出力$25 per 1M）で、1用件あたり10円前後。
`MODEL` に `claude-sonnet-5`、`EFFORT` に `low` を入れると安く・速くなります。
Claude側は前払いのクレジット式なので、自動チャージを切っておけば残高を使い切った時点で止まります。

**ウェブ検索は Claude のときだけ使えます。** Gemini のときは、手元の道具で確かめられないことは
「調べていません」と断るようにしてあります。

## 気をつけること

- **Webhook URLは人に渡さないでください。** 合言葉つきのURLを知られると、
  あなたのカレンダーやメモに触れる入り口を渡すことになります。
- **APIキーとアクセストークンをこのリポジトリに書かないでください。**
  どちらもスクリプト プロパティにだけ置いてください。
- GASはリクエストのヘッダを受け取れないため、LINEの署名検証（`X-Line-Signature`）は
  使えません。代わりにURLの合言葉で弾いています。持ち主のLINE userId 以外は
  無視するので、二重の守りにはなっています。
- 会話の記録・メモ・覚えたことは、**あなたのGoogleドライブの中**のスプレッドシートに
  だけ入ります。Claudeへは会話の文脈として送られます。

## ファイル構成

```
src/appsscript.json    権限とタイムゾーンの宣言
src/00_config.gs       設定のまとめ（鍵は入れない）
src/10_util.gs         日付・ID・文字列の小道具
src/20_store.gs        スプレッドシートの読み書き
src/30_line.gs         LINEとのやりとり
src/40_llm.gs          頭脳の窓口。どのAIを使うかはここで切り替わる
src/41_claude.gs       Claudeで動かすときの中身（PROVIDER=claude）
src/42_gemini.gs       Geminiで動かすときの中身（PROVIDER=gemini・既定）
src/50_tools.gs        秘書に持たせる道具（予定・用事・メモ・記憶・検索）
src/60_brain.gs        人格と記憶。夜のふりかえり
src/70_main.gs         LINEからの入口（doPost）
src/80_scheduler.gs    朝のお知らせ・催促・ふりかえりの仕掛け
src/90_setup.gs        最初の1回だけ動かすもの（setup / status / test* / listGeminiModels）
```

## 増やしたいとき

道具を足すのがいちばん手数が少ないです。`50_tools.gs` の `toolDefs_()` に説明を書き、
`runTool_()` に実行を足すだけで、秘書はそれを使いはじめます。

Gmailの下書き作成、スプレッドシートへの記帳、Googleドライブの検索などは、
GASから直接触れるので同じやりかたで足せます。その場合は `appsscript.json` の
`oauthScopes` に必要な権限を追記し、デプロイし直してください。
