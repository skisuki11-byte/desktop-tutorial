# 日大基礎学テスト世界史 一問一答 ｜ 過去問徹底分析版

土浦日本大学高校・基礎学力到達度テストの過去問（令和5・6・7年度）**全28ページを1枚ずつ読解**し、
同じ出題形式・同じ難易度帯で作った一問一答アプリです。スマホ用。

## 中身

- **全434問**（基本98／標準317／やや難19）
- 難易度は対策塾各社の共通見解「教科書レベル〜共通テスト相当・奇問なし」に合わせている
- 形式は過去問に合わせて2種類
  - **語句問題 387問** … 一問一答としても、4択としても解ける
  - **正誤の組合せ・年代整序 47問** … 4択のみ（選択肢の順序に意味があるため並べ替えない）
- 全問に解説つき。解説には「なぜ他の選択肢が誤りか」「どこがすり替えられやすいか」を入れています

### 初版からの重要な訂正

初版では Notion の分析を引き継いで「令和5は8大問57問がすべて必須」としていましたが、
**実物の表紙には「Ⅶ・Ⅷのうちから1題を選んで解答すること」と明記されており、誤りでした。**
令和7も「1〜5は必須問題。6・7についてはいずれか1題を選択」とあります。
対策塾各社の「共通問題は第一次世界大戦とロシア革命まで、選択問題はテーマ史かそれ以降の近代史」
という説明とも一致します。章立てをこの実態に合わせて組み直しました。

## 過去問カバレッジ（`node coverage.js`）

令和5・6・7の実物157問（歴史総合の10問を除く）を1問ずつ読み、各設問を解くのに
必要な知識が問題バンクに入っているかを機械的に照合している。

```
令和5: 57/57 問  (100%)
令和6: 50/50 問  (100%)
令和7: 50/50 問  (100%)
合計: 157/157 問  (100%)
うち図表問題（地図・写真・系図）16問は知識面のみ対応
→ 図表を全部落とした場合は 89.8%
```

つまり**本アプリを完全に仕上げれば、文章題は理屈の上では全問対応でき、
図表16問（約10%）を資料集で埋めれば90点台が射程に入る**。
図表を全部落としても約90%で、80点の目標には届く計算になる。

問題を追加・修正したら `node coverage.js` を再実行して、穴が開いていないか確認する。

## すすめ方（アプリが導く一本道）

「どこからやればいいか分からない」を無くすため、ホームには**今日やること1つ**だけを出す。
ほかのモードと設定は折りたたみの中。

なお「すすめ方」は操作するものではなく**説明のための表示**なので、
押せそうに見えないよう強調はしていない。実際に押すのは「今日の◯問」だけ。

```
STEP 1  ぜんぶ一度は解く          ← 全問に触れて、知らないものを洗い出す
STEP 2  あやふやな問題をマスターにする  ← 2回続けて正解できたら「覚えた」
STEP 3  本番形式60問で80点を確認する
```

いま自分がどのステップかは自動判定して1つだけ強調する。

## 習得の判定と進捗（mikan・Duolingo の定石を採用）

- **4段階**（まだ／あやふや／あと一歩／覚えた）。1回正解しただけでは「覚えた」にしない。
  **2回続けて正解**して初めてマスター扱い。間違えたら振り出しに戻る
- 判定を待たずに、解いたあとの**「もう覚えた」チェック**で自分でマスターにもできる。
  もう一度押せば取り消せる（直前の状態に戻る）
- 進捗が0%のままだと「進んでいない」ように見えるため、
  少しでも進んでいれば最低1%を表示する（1問は326分の0.2で四捨五入すると0になってしまう）
- 進捗リングは段階に応じた部分点（0 / 0.2 / 0.6 / 1）で計算する。
  1回解いただけでもリングが動くので、初日から進んでいることが分かる
- **試験日からの逆算**で1日のノルマを毎日計算し、「1日◯問なら間に合う」と明示する
- 連続日数を表示（Duolingo のストリークと同じ狙い）

## 出題アルゴリズムの検証（38日シミュレーション）

試験日（2026年9月24日）までに本当に終わるのかを、同じロジックで回して確かめた。
**当初の「新規優先」では全く間に合わないことが分かり、設計を変更した。**

| 出題の優先順位 | 1日20問・正答率80%で覚えられた数 |
|---|---|
| 新規を優先（当初） | 73問 / 326問（22%） |
| **あと一歩を最優先（採用）** | **195問 / 326問（60%）** |

新規ばかり追いかけると「あと一歩」が滞留して永久に定着しない。
もう1回正解すれば覚えたことになる問題を先に片づけるのが最も効率が良い。

そのうえで必要なペースを逆算した結果が**1日35問**（当初の想定は20問だった）。

```
試験まで61日・正答率80% → 覚えた 328/326問（101%）
正答率70%             → 289/326問（89%）
正答率65%             → 269/326問（83%）
```

1日のノルマは残り日数から毎日計算し、5問単位に切り上げる（切り捨てると必要量に届かない）。

1日のノルマは上限45問。それでも間に合わない計算になったら、
増やし続けるのではなく「必須の①〜⑥を優先しましょう」と正直に伝える。

## 出題の仕組み

- **本番と同じ配分で出す。** 全範囲の出題は「必須6章＋自分が選ぶ選択枠1つ」に限定し、
  必須:選択 = 2:1（令和7の40問:20問と同比）で抽出する。選ばない選択枠は出さない
- **必須6章は均等に出す。** 本番ではどの大問も配点が同じなので、収録数の多い章
  （①67問）に偏らないよう章ごとに順番に取る。収録30問の⑥も同じ重みになる
- 語句問題は毎回 選択肢をシャッフルするので、位置で覚えてしまうことがない
- 記録（正答率・苦手リスト）は端末のブラウザに保存。サーバーには何も送りません

## 使い方

`dist/index.html` が1ファイル完結版です。スマホに保存すればオフラインでも動きます。

## 開発

```
node check.js    # 問題データの検算（選択肢の数・正解の一致・id重複・解説の有無）
node build.js    # dist/index.html と dist/artifact.html を生成
```

問題を足すときは `data/chN.js` に追記して `node check.js` を通してから `node build.js`。

### 問題データの形

```js
{
  id:"c3-13",       // 一意
  lv:1,             // 1=基本 2=標準 3=やや難
  t:"qa",           // qa=一問一答むき（選択肢シャッフルあり） mc=4択専用
  q:"問題文",
  a:"こたえ",        // c[ans] と一致していること（check.js が検算する）
  c:["…","…","…","…"],
  ans:0,
  e:"解説",
  tag:["イスラーム","ムハンマド"]
}
```

## 既知の限界

- **地図・写真・系図の問題は出せません。**過去問では毎年5問前後出ており、資料集での補完が必須です
- 難易度・範囲は年度で変動します。本アプリは令和5・6・7の3年分から推定したものです
