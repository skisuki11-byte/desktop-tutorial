# 世界史 一問一答 ｜ 基礎学力到達度テスト（世界史探究）対策

土浦日本大学高校・基礎学力到達度テストの過去問（令和5・6・7年度）を分析し、
同じ出題形式・同じ難易度帯で作った一問一答アプリです。スマホ用。

## 中身

- **全346問**（基本97／標準237／やや難12）
- 難易度は対策塾各社の共通見解「教科書レベル〜共通テスト相当・奇問なし」に合わせている
- 形式は過去問に合わせて2種類
  - **語句問題 305問** … 一問一答としても、4択としても解ける
  - **正誤の組合せ・年代整序 41問** … 4択のみ（選択肢の順序に意味があるため並べ替えない）
- 全問に解説つき。解説には「なぜ他の選択肢が誤りか」「どこがすり替えられやすいか」を入れています

## 章立て（＝実際の大問構成）

令和5・6・7の3年とも、大問1〜5は同じ並びで出題されていました。章番号はその実データです。

| 章 | 範囲 | 問題数 | 根拠 |
|---|---|---|---|
| ① | 古代ギリシア・ローマ＋中世西欧の入口 | 53 | 3年連続 大問1 |
| ② | 古代インド・古代中国＋東南アジア | 49 | 3年連続 大問2 |
| ③ | 古代オリエント・イスラーム世界 | 48 | 3年連続 大問3 |
| ④ | モンゴル帝国・中世〜近世東アジア（宋元明清） | 48 | 3年連続 大問4 |
| ⑤ | 近世ヨーロッパ（大航海〜市民革命） | 50 | 3年連続 大問5 |
| ⑥ | 近代欧米・ロシア・19〜20世紀 | 72 | 塾各社「共通問題は第一次大戦とロシア革命まで」 |
| 探 | テーマ史・史料型 | 26 | 令和7 大問6（世界史探究の選択問題）対応 |

大問⑥について。当初は「年度で出方が変わる変動枠」と位置づけていましたが、日大付属向けの対策塾各社が
「共通問題（必須）の範囲は詳説世界史の第14章＝第一次世界大戦とロシア革命まで」と説明しているため、
必須扱いに改めて問題数を増やしました（令和5では近代欧米・ロシア史・19〜20世紀が丸ごと3大問を占めています）。

### 対策塾の情報とのクロスチェック

| 塾側の指摘 | 本アプリでの反映 |
|---|---|
| 難易度は易しめ〜標準、教科書レベル。奇問は出ない | 難易度タグを実態に合わせ、やや難は12問のみに |
| 中国王朝は 建国者・制度（土地・税・兵制）・反乱 をセットで | 府兵制・陳勝呉広の乱などを追加し3点セットを網羅 |
| ギリシア・ローマの民主政の成立過程や戦争の経過は年代整序になりやすい | アテネ民主政・ローマ身分闘争の年代整序を追加 |
| 資料集を常に併用すること（地図・写真・系図） | **アプリでは扱えないため、ホーム下部に注意書きを表示** |

## 出題の仕組み

- 未出題の問題を最優先、次に間違えた問題を優先して出す（同じ問題ばかり出ないよう乱数で散らす）
- 間違えた問題は「まちがい直し」に自動でたまる
- 語句問題は毎回 選択肢をシャッフルするので、位置で覚えてしまうことがない
- 記録（正答率・苦手リスト）は端末のブラウザに保存。サーバーには何も送りません

## 使い方

`dist/index.html` が1ファイル完結版です。スマホに保存すればオフラインでも動きます。

## 開発

```
node check.js    # 問題データの検算（選択肢の数・正解の一致・id重複・解説の有無）
node build.js    # dist/index.html と dist/artifact.html を生成
```

問題を足すときは `data/chN.js` に追記して `node check.js` を通してから `node build.js`。

### 問題データの形

```js
{
  id:"c3-13",       // 一意
  lv:1,             // 1=基本 2=標準 3=やや難
  t:"qa",           // qa=一問一答むき（選択肢シャッフルあり） mc=4択専用
  q:"問題文",
  a:"こたえ",        // c[ans] と一致していること（check.js が検算する）
  c:["…","…","…","…"],
  ans:0,
  e:"解説",
  tag:["イスラーム","ムハンマド"]
}
```

## 既知の限界

- **地図・写真・系図の問題は出せません。**過去問では毎年5問前後出ており、資料集での補完が必須です
- 難易度・範囲は年度で変動します。本アプリは令和5・6・7の3年分から推定したものです
