# 売電管理アプリ（市原・富津・竹原）

太陽光3基の**売電額・発電量・利益**を月別／年度別に見て、
電力会社の明細を**カメラで撮って追記**できるブラウザアプリです。

`index.html` を開くだけ。インストールもビルドも要りません。
スマホなら「ホーム画面に追加」でアプリとして使え、追加後はオフラインでも開きます。

## 画面

| タブ | 出るもの |
|---|---|
| ホーム | 3基合計と発電所ごとの当年実績。前年同期比つき。月別の棒グラフ（薄い棒＝前年） |
| 月別 | 発電所ごとの12ヶ月表。売電額・発電量・**前年同月**・前年差・前年比・返済／経費・**利益** |
| 年度別 | 2018年〜の売電額・発電量・確定利益を横並び。折れ線で推移 |
| グラフ | 発電所内訳の積み上げ棒／発電量／利益／前年同月との差 |
| カメラ入力 | 明細を撮って読み取り。手入力もここ。取り込んだぶんの一覧とシートへの書き戻し |
| 設定 | APIキー、シートのURL、Excel／JSON書き出し |

文字は大きめ（本文18px、金額は約2.5rem）にしてあります。暗い画面にも対応。

## 数字の決め方

- **月の利益** ＝ その月の売電額 −（ローン＋草刈り＋電気＋償却資産税…）
  経費は元シートの W〜Z 列の月額をそのまま使い、どの年にも当てはめています。
- **年の合計** は「実績の入っている月ぶん」だけ。経費も同じ月ぶんだけ引くので、
  `売電額 − 返済・経費 = 利益` が表の上でも合います。
- **前年同期比** は、今年 実績のある月と同じ月だけを前年から切り出して比べます。
  7月までしか入っていない年を前年の12ヶ月と比べても意味がないためです。
- **確定利益**（年度別タブ）は元シートの「確定利益」行。税まで引いた手取りです。
- まだ実績のない月は **0円ではなく空欄（—）**。0と書くと落ち込んだように見えるためです。
- 3基そろっていない月には「◯基のみ」の印を付け、前年比を出しません。

## カメラでの読み取りについて

「設定」タブに Anthropic の APIキー を登録すると、明細を撮って
対象年月・売電額・発電量を読み取れます。

- 読み取った値は**そのままでは保存されません**。画面で直せる形に出し、
  「取り込む」を押したときだけ入ります
- 例年の同じ月の実績・契約単価と突き合わせ、桁がおかしいときは警告を出します
- APIキーはブラウザ（localStorage）にのみ保存され、送信先は `api.anthropic.com` だけです
- **APIキーをこのリポジトリに書き込まないでください**。共用のパソコンでは登録しないでください

## Googleスプレッドシートへの書き戻し

「設定 → シートのURL」に Apps Script のウェブアプリURLを登録すると、
元の「売電結果」シートの**該当セルに直接**書き込めます（行＝月、列＝年）。
入れ方は [`tools/drive-webapp.gs`](tools/drive-webapp.gs) の先頭に書いてあります。

- **読む**…「シートから読み込む」を押したときだけ。違いを一覧で見せてから取り込みます
- **書く**…「シートに書き込む」を押したときだけ。書いた内容は
  シートの「アプリ書込履歴」に残ります
- xlsx のままでは Apps Script から書き込めないので、
  一度「Googleスプレッドシートとして保存」しておく必要があります
- タブ名は「累計」を探し、見つからず**タブが1枚だけ**ならそれを使います
  （CSVから作ったシートはタブ名が「Untitled」になることがあるため）
- 2027年ぶんを入れるときは、シートに列を足したうえで `gs` の `YEAR_LAST` を直してください
- **URLを知っている人はシートを読むことも書き換えることもできます。**
  ご自身だけが持ち、他の方には渡さないでください

## ファイル構成

```
index.html              画面
css/style.css           スタイル（明／暗、文字大きめ）
js/data.js              元シートから取り出した実績（tools/extract.py が作る。手で直さない）
js/store.js             元帳＋追記を重ねて、表示する数字を作る
js/chart.js             SVGのグラフ（外部ライブラリなし）
js/ocr.js               明細写真の読み取りと検算
js/sync.js              シートとのやりとり（押したときだけ）
js/xlsx.js              Excel書き出し
js/app.js               画面の組み立て
sw.js                   オフラインで開けるようにする
tools/extract.py        xlsx → js/data.js
tools/drive-webapp.gs   シート側の窓口（Apps Script）
```

## データの取り込み直し

元の xlsx を更新したら、`js/data.js` を作り直します。

```
pip install openpyxl
python3 tools/extract.py 売電結果2026.xlsx > js/data.js
```

3基合計が元シートの合計行と合うかを自分で検算し、合わなければ止まります。
端末に貯めた追記は `js/data.js` とは別なので、作り直しても消えません。

## 保存先について

このリポジトリに売電の実績は `js/data.js` として入っています（金額・発電量のみ）。
端末で足した入力は localStorage にだけ入り、押さないかぎりどこにも送りません。
