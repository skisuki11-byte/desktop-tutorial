# つぐいえ — 画面デザイン（Claude Design）

Claude Design のキャンバスとして公開しているデザインのソース。
アートボード1枚＝`.dc.html` 1ファイル。`canvas.json` が配置と見出しを持つ。

キャンバス: https://claude.ai/artifact/U6DiCwkYSEEwxvcXLHuthP （非公開。共有はページの Share から）

| ファイル | 画面 |
|---|---|
| `Main.dc.html` | ホーム（期限タイムライン） |
| `Learn.dc.html` | まなぶ（いまの時期の記事） |
| `Sim.dc.html` | はかる（試算結果） |
| `Experts.dc.html` | 1 相談先をえらぶ（宅建士・弁護士・税理士、紹介料の有無） |
| `Form.dc.html` | 2 相談内容の入力 |
| `Confirm.dc.html` | 3 送信前の確認 |
| `Done.dc.html` | 4 送信完了（受付番号・後日メール・自動返信なし） |

画面どうしはリンクでつながっており、キャンバスの再生ボタンで流れを試せる。
配色は藍 `#27497A` を唯一のアクセントにし、期限・注意だけ朱 `#B2462B` を使う。
