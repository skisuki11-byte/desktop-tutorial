# つぐいえ — 画面デザイン v2（Claude Design・ポップ版）

Claude Design のキャンバスとして公開しているデザインのソース。
アートボード1枚＝`.dc.html` 1ファイル。`canvas.json` が配置と見出しを持つ。

キャンバス: https://claude.ai/artifact/KeySnDSGKCsRiHKieaF7AR （非公開。共有はページの Share から）
前の版（v1・落ち着いた藍）は `v1/` に残している。

## 方向

「固い」→「ポップだけど、はしゃがない」。

| 参考にした事例 | 取り入れたこと |
|---|---|
| Headspace（重い題材を、丸い形とキャラクターで親しみやすくした） | 丸ゴシックの見出し、案内役「いえまる」、色つきのタイル |
| Duolingo（進み具合と、押したくなる厚みのボタン） | 進み具合のメーター、影で厚みをつけたボタン、1画面1問 |
| Empathy（遺族向けアプリ。手続きをやることリストにして1つずつ進める） | やること → くわしく学ぶ →「済」→ 次のやること |
| Facebook「Year in Review」(2014) の失敗（亡くなった家族の写真を祝う演出で出した） | 紙吹雪やお祝いの演出は使わない。「ひとつ進みました。おつかれさまでした」まで |

## アートボード

| ファイル | 画面 |
|---|---|
| `Main.dc.html` | ホーム（進み具合・はかる／総合窓口の入口・やること） |
| `Task.dc.html` | やることの詳細（知っておきたいこと・流れ・用意するもの・困ったら・「済」にする） |
| `TaskDone.dc.html` | 済にしたあと（次のやることへ） |
| `Sim.dc.html` | はかる（1画面1問） |
| `SimResult.dc.html` | はかる（試算結果） |
| `Consult.dc.html` | 相続の総合窓口（不動産・弁護士・税理士） |
| `Form.dc.html` | 相談内容の入力 |
| `Confirm.dc.html` | 送信前の確認 |
| `Sent.dc.html` | 送信完了（受付番号・後日メール・自動返信なし） |
| `Parts.dc.html` | 色・文字・ボタン・いえまる |
