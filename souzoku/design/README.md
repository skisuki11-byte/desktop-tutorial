# つぐいえ — 画面デザイン v3（Claude Design・あたたかい藍）

Claude Design のキャンバスとして公開しているデザインのソース。
アートボード1枚＝`.dc.html` 1ファイル。`canvas.json` が配置と見出しを持つ。

キャンバス: https://claude.ai/artifact/9zBwkNTTduiCixcUWneACF （非公開。共有はページの Share から）
前の版は `v2/`（ポップ）、`v1/`（落ち着いた藍）に残している。

## 方向

「ポップすぎる（v2）」と「硬すぎる（藍1色の試作）」の間。信頼の藍に、あたたかさを足す。40代以降の利用を想定。

| 参考にした事例 | 取り入れたこと |
|---|---|
| Headspace（重い題材を、やわらかいイラストで親しみやすくした） | 丘・家・木・お日さまの平らなイラストを画面の頭に置く |
| Lemonade・Monzo（お金の話を、案内役と会話調でやさしくした） | いえまるをナビに。ホームで「次にやること」を案内し、ボタン1つで進める |
| デジタル庁・GOV.UK（高齢の方も使う公的サービス） | 本文は UD 書体（BIZ UDPゴシック）17px 以上、主な操作ボタンは1画面に1つ |
| Office アシスタントのイルカ（案内役が勝手に出てきて嫌われた） | いえまるは1画面1回・1〜2文まで。勝手に飛び出さない |
| Facebook「過去の思い出」（亡くなった家族の写真を祝う演出で批判された） | お祝いの演出はしない |

## 決まりごと

- 地は生成り #FAF7F1、主役は藍 #2A5594 の1色（ボタン・リンク・数字）
- 若草・山吹・柿はイラストといえまるだけ。文字やボタンには使わない
- 赤は期限切れ・30日以内・削除、緑は「済」「無料」だけ
- 見出しと大きな数字は Zen 丸ゴシック、本文は BIZ UDPゴシック
- ボタンは高さ52px以上・角丸14px・影や厚みなし
