# 第2回 点検（2026年9月27日）：システム構成・バグ・脆弱性・ミドルウェア

## A. システム構成

| 部分 | 中身 | 判断 |
|---|---|---|
| アプリ本体 | HTML / CSS / JavaScript だけ（ライブラリ・npm 依存なし）。GitHub Pages で配信 | 依存が無いので、ライブラリの脆弱性やバージョン切れの心配がない |
| 端末の保存 | localStorage（`tsuguie.v1`）。相談の入力は保存しない | 変更なし |
| オフライン | Service Worker（network-first） | 下のバグを修正 |
| 相談・相場の中継 | Google Apps Script（V8 ランタイム）→ Gmail / 不動産情報ライブラリ API | 下の脆弱性を修正 |
| 外部読み込み | Google Fonts（CSS2 API・現行版） | 変更なし（プライバシーポリシーに記載済み） |

**ミドルウェアのバージョン**：アップデートが必要なものはありませんでした。
- アプリはライブラリを使っていないため、更新対象なし
- GAS は最新の V8 ランタイムを指定済み（旧 Rhino ランタイムは Google が廃止済み。移行は不要）
- テスト用の Playwright / Chromium は開発環境だけで使い、公開物には含まれない

## B. 見つけて直したバグ

| バグ | 起きること | 直し方 |
|---|---|---|
| 初めて開いたとき、画面が1回勝手に読み込み直される | Service Worker が制御を始めた合図（controllerchange）を「新しい版が来た」と取り違えていた。オープニング画面がちらつく | 最初から制御されていなかったときは読み込み直さない（旧版2回→新版1回を確認） |
| 圏外で画像やJSが無いとき、代わりにアプリのHTMLを返す | 画像の代わりにHTMLが返り、表示が壊れうる | 代わりにアプリの入口を返すのは「ページを開くとき」だけにした |
| 転送（リダイレクト）された応答を保存する | iPhone の Safari では、それを使って開くと失敗することがある | 転送を経た応答・他サイトの応答は保存しない |
| 圏外で `index.html?…` のように末尾が付いたURLを開くと開けない | ホーム画面のアイコンや共有リンクで起きうる | 圏外でページを開くときは末尾の `?…` を無視して探す |
| プライバシーポリシーに、アプリで選んだ「画面の色」「文字の大きさ」が反映されない | ダークにしていても白い画面になる | 設定を読んで当てる小さなスクリプトを追加 |
| 「もどる」と「戻る」が混在 | 表記ゆれ | 「戻る」に統一 |

## C. 見つけて直した脆弱性・弱いところ

| 項目 | 危険 | 直し方 |
|---|---|---|
| バックアップ読み込み時の試算の検査が甘い | 改ざんファイルで、巨大な数字・文字列の数字・未知の項目が入り、計算や表示が崩れうる | 試算を決まった形に作り直す（金額は0〜1,000億円、人数は1〜50人、文字は長さを切る、知らない項目は捨てる） |
| 大きなファイルを読み込ませられる | 端末が固まる | 1MB を超えるファイルは読まない |
| クリックジャッキング（他サイトの枠に入れて押させる） | GitHub Pages はヘッダー（frame-ancestors）を付けられない | 枠の中で開かれたら、画面を出さずに「直接開く」リンクだけを出す |
| プライバシーポリシーに CSP が無い | 読み込み先の制限がない | CSP・リファラー制限を追加（通信は一切しない設定） |
| GAS：返信先（Reply-To）に `,` や `<>` 入りのアドレスを入れられる | 窓口が返信したときに、相談者以外にも届く宛先を仕込める | アドレスの形を厳しくし（アプリ側も同じ形）、`, ; < > "` や空白を拒否。携帯の古い形式（`..` を含む）は通す |
| GAS：ロック待ちが長いと例外になる | アプリに HTML のエラーが返り、「通信できません」と誤表示 | 待ちきれないときは「混み合っています」を返す |
| GAS：巨大な送信を読んでしまう | 処理時間の浪費 | 20KB を超える送信は読まずに断る |
| GAS：都道府県コードの範囲 | 01〜47 以外で外部APIを呼ぶ | 範囲外は断る |
