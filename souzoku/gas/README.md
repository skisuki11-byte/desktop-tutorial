# 相談フォームの中継（Google Apps Script）の設定

アプリの相談フォームは、ここにある `Code.gs` を Google Apps Script（GAS）で動かして、相続の総合窓口にメールで届けます。窓口が内容を見て、提携の不動産会社（宅建士）・弁護士・税理士に振り分けます。自前のメールサーバーは要りません。GAS は受け取った内容を転送するだけで、どこにも保存しません。

## 1. スクリプトを作る

1. 運営者の Google アカウントで https://script.google.com を開き、「新しいプロジェクト」を作る
2. エディタの `コード.gs` の中身を、このフォルダの `Code.gs` で置き換えて保存
3. 左の歯車（プロジェクトの設定）→「スクリプト プロパティ」に、次の1つを追加する

| プロパティ | 値 |
|---|---|
| `TO_MADOGUCHI` | 相続の総合窓口の受信用メールアドレス（いまは `halufuway@gmail.com`） |

## 2. 動作を確かめる

エディタ上部で関数 `testSend` を選んで「実行」。初回は権限の確認が出るので許可する。`TO_MADOGUCHI` の宛先にテストメールが届けば成功。

## 3. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 次のユーザーとして実行：**自分**
3. アクセスできるユーザー：**全員**
4. 「デプロイ」を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー

## 4. アプリに URL を設定する

`souzoku/js/config.js` の `endpoint` に、コピーした URL を入れる。あわせて、窓口の運営会社・提携先の名前・免許番号（`madoguchi` の `[ ]` の部分）と `replyDays`（返信の目安日数）、`operator`（運営者名）も書き換える。`privacy.html` の `[ ]` も同様に。

## 5. 送信済みの控えを自動で消す（推奨）

MailApp で送ったメールは、運営者の Gmail の送信済みフォルダに控えが残る。「保存しない」方針に合わせて、1日1回消す。

1. 左の時計アイコン（トリガー）→「トリガーを追加」
2. 実行する関数：`cleanupSent`、イベントのソース：時間主導型、日付ベースのタイマー
3. 初回に Gmail の権限を求められたら許可する

## 上限と注意

- 個人の Gmail アカウントでは、1日に送れる宛先は **100件** まで（Google Workspace なら1,500件）。相談1件につき1件使う
- スクリプト側でも 1時間あたり30通の上限をかけている（`MAX_PER_HOUR`）。悪用されても、決まった1つの宛先にしか届かず、上限で止まる
- ユーザーへの自動返信はしない。アプリの確認画面と完了画面で「自動返信メールは送られません」と案内している
- 週に1回はアプリから実際に送信して、届くことを確かめる（届かないのに誰も気づかない、を防ぐ）
- `Code.gs` を直したら、「デプロイを管理」から同じデプロイの新しいバージョンを作る（URL は変わらない）
