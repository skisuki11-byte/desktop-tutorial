# 春高チケット — 応援チケットの申し込みと集計

春高バレー（土浦日大 女子バレーボール部）の応援チケットを、各家庭がスマホから申し込み、役員が「購入する枚数（日付×区分）」と「誰が何枚・いくらか」を確認するための Web ページです。

| 画面 | 使う人 | URL |
|---|---|---|
| 申し込み（`index.html`） | 各家庭 | `…/ticket/` |
| 集計（`admin.html`） | 役員（数名・合言葉で入る） | `…/ticket/admin.html` |

- 日付：1/4（月）・1/5（火）・1/6（水）／区分：大人 ¥2,000・高校生以下 ¥1,500（`js/config.js` と `gas/Code.gs` の両方。食い違いはテストで検出）
- 申し込み画面には役員ページへのリンクを置かない
- データは役員の Google スプレッドシート（シート「チケット申込」）に貯まる。設定手順は [`gas/README.md`](gas/README.md)

## 申し込みの流れ（各家庭）

1. **入力**：お名前・コートネーム（任意）・日付×区分の枚数（−／＋）。合計枚数と金額がその場で出る。
   いちばん間違えやすい「部員の分は入れない・追加注文はできない」を入力欄の上に出す
2. **確認**：お名前・日付ごとの枚数・合計枚数と金額を大きく表示し、5つの注意事項をすべて並べる。［修正する］［申し込む］
3. **完了**：受付番号つきで同じ内容を表示。［修正する］［閉じる］

## 集計画面（役員）

1. **購入する枚数**：合計と金額、日付×区分の内訳表（チケットを買うときにそのまま使える）
2. **集金**：集金済みの家庭数と金額。押すと「集金まだ」の家庭だけが並ぶ
3. **受け渡し**：押すと「まだ渡していない」家庭だけが並ぶ

- 一覧は1家庭ずつ：お名前・コートネーム・日付ごとの内訳・枚数と金額・［集金］［受け渡し］・［修正］［取り消し］
- 取り消しと、集金・受け渡しの記録を外すときは確認が出る。取り消し後も［元に戻す］できる
- ［集計をコピー（LINEに貼る用）］［CSVで保存］［表をコピー］

## 確かめ方

- `node ticket/tests/gas.test.js`（集計先のテスト）
- `js/config.js` の `endpoint` を空にするとデモ表示（合言葉 `demo`）
