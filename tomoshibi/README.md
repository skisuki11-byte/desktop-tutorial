# ともしび

亡くなったペットのお墓。毎日ひらき、節目を数え、一年に一度だけ強く灯ります。

`index.html` をブラウザで開くだけ。インストール・ビルド・通信は一切不要で、
スマホでもオフラインで動きます。記録は端末内（localStorage / IndexedDB）にだけ保存されます。

元になった企画：Notion「ともしび — ペット供養アプリ 企画（v2 / 検証済み）」（2026-09-13・一次検証済み）
UI案とその根拠：[`proposal.html`](proposal.html) ／ [`docs/UI設計.md`](docs/UI設計.md)

## 画面

```
おむかえ ─→ お墓 ─→ お参り（4動作） ─→ お参りのあと
              │
              ├─ あの日まで   四十九日・月命日・誕生日・一周忌・三回忌・七回忌
              ├─ アルバム     端末の写真を期間で章立て。出さない期間を指定できる
              ├─ てがみ       節目に一通、3行
              │
          命日の予告 ─→ 再会の6秒
              │
             設定
```

## つくりの要点

- **お墓で押せるものは1つだけ。** 数字は「次に来る節目まであと◯日」の1行のみ。
  四十九日がまだ先のあいだは、日付順で先に来る月命日よりそちらを出す。
- **お参りは順序固定の4動作**（灯明→水→ごはん→花）。スキップも並べ替えもできない。
  完了時におりんが一打鳴る（WebAudioで合成。毎回まったく同じ音）。
- **会う回数は設定させず、日数で自動的に減る。** 毎日 → 月命日 → 季節ごと → 命日。
  「もう少し会いたい／間をあける」で1段だけ動かせる。
- **命日の再会は自動再生しない。** 何が起きるかを先に全部伝え、「やめておく」を
  主ボタンと同じ大きさで並べる。終端は「また来年、この日に。」
- **「すべて手元に持ち出す」を設定の最上段に置く。** 写真ごと1つのJSONに書き出せる。
  引き止めダイアログは置かない。

## 実装しないと決めたUI

連続お参り記録（ストリーク）／達成バッジ・紙吹雪／ランダムに届く思い出／
退会引き止め／他人との比較／常時対話できるAIチャット。

いずれも継続率を確実に上げる実証済みの手法です。採らない理由は
[`docs/UI設計.md`](docs/UI設計.md) に事例つきで書いてあります。**足したくなったら先にそれを読んでください。**

## この端末だけで動く版と、製品版の違い

| | この版 | 製品版の想定 |
|---|---|---|
| てがみ | 節目と季節から組み立てた定型文（画面にその旨を表示） | AIが写真と記録から書く |
| 再会の6秒 | 登録した1枚が近づいて止まる | 写真から生成した6秒の動画＋自動品質チェック |
| 保存先 | 端末内のみ | Supabase / Cloudflare R2 |
| 家族共有 | なし | Phase 2 |

## 確認のしかた

設定の「日付を仮に進めて確かめる」で、四十九日・一周忌・三回忌の画面を
待たずに見られます。通常は「今日」のままにしてください。

## ファイル

```
index.html              アプリ
css/style.css           配色・書体・余白のトークン
js/store.js             保存層と、日付・節目・逓減フェーズの計算
js/app.js               画面の組み立て
manifest.webmanifest    ホーム画面に追加するため
sw.js                   オフラインで開くため
proposal.html           UI案（企画を画面に落とした提案書）
docs/UI設計.md          判断と根拠
```

## 注意

- 写真を登録していないあいだは、犬のシルエットが代わりに出ます。
- 「つらいときの相談先」は、実在と受付状況を確認できた窓口だけを載せます。
  確認できていないものは載せません。
