ペット供養アプリ「ともしび」（プロジェクト名：わんずのともしび）のUI提案。
`index.html` をブラウザで開くだけで見られます。ビルド・通信・依存ライブラリはありません。

元になった企画：Notion「ともしび — ペット供養アプリ 企画（v2 / 検証済み）」（2026-09-13 / 一次検証済み）

## 画面一覧

```
おむかえ ─→ お墓（0〜49日／毎日） ─→ お参りの4動作 ─→ お参りのあと
                  │
                  ├─ あの日まで（カウントダウン）
                  ├─ アルバム（AIの章立て）
                  ├─ てがみ
                  │
            お墓（50日〜半年／月命日）※通知が自動で逓減
                  │
          命日の予告 ─→ 再会の6秒
                  │
                 設定
```

## 設計の骨子

1. **画面でいちばん明るいものが灯り。** 彩度のある色は灯りの橙1色だけ。
2. **お墓のホームで押せるものは1つだけ。** 数字は「次の節目まであと◯日」の1行のみ。
3. **通知の逓減は設定させず、既定で自動進行する。** 戻したい人だけが手で戻す。
4. **再会ムービーは自動再生しない。** 何が起きるかを先に全部言い、「やめておく」を同じ大きさで並べる。
5. **ストリーク・バッジ・紙吹雪・引き止め・比較は実装しない。**

詳細な根拠は [`docs/UI設計.md`](docs/UI設計.md)、またはページ内の各画面キャプションを参照。
