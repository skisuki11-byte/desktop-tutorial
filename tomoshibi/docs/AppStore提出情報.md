# App Store Connect 提出情報（下書き）

App Store Connectの各入力欄にそのまま貼れるように、項目ごとに分けてある。
「〜と思われる」と書いた判断（年齢制限など）は最終的にApple側の審査・
質問票で決まるものなので、目安として扱うこと。

## 基本情報

- **名前**：ともしび
- **サブタイトル**（30字以内）：亡くなったペットと、いつも一緒に
- **プロモーションテキスト**（170字以内・審査なしでいつでも変更可）：
  大切な家族を見送った、その日から。おまいりして、庭に花を増やして、あの子への手紙を書く。アカウント登録もサーバー通信も一切ない、あなたとその子だけの場所です。
- **価格**：無料（アプリ内課金・広告なし。収益化の仕組みは現状組み込んでいない）
- **サポートURL**：GitHub PagesのURL（例：`https://<ユーザー名>.github.io/desktop-tutorial/tomoshibi/`）。具体的な問い合わせ先は`privacy.html`に記載のメールアドレス
- **マーケティングURL**：同上、または空欄でも可
- **著作権**：発行年＋開発者名（例：2026 ◯◯）

## カテゴリ

- **プライマリ**：ライフスタイル
- **セカンダリ**：なし（無理に付けなくてよい。強いて言えば「ヘルス／フィットネス」だが、フィットネス色の強いカテゴリなので今回は見送り推奨）

## 説明文（4000字以内）

```
亡くなったペットのための、あなただけのおうちです。

いつも会いに行ける場所を。
名前を呼んで、灯りをともして、お水とごはんとお花をそなえる。おまいりのたびに、庭に花が1つ増えていきます。連続記録は数えません。何日あいても、花は枯れません。

■ こんなことができます
・毎日のおまいり（灯り・お水・ごはん・お花を、いつも同じ順番で）
・好きだったものをそなえる（さつまいも、ボールなど、3つまで）
・おまいりの庭で、増えていく花と、いっしょにいた日数を見る
・あの子への手紙を書いて、とどける
・四十九日・百か日・月命日・お誕生日・一周忌・三回忌まで、あと何日かを知る
・いまの気分を5段階で記録（良し悪しではなく、波のかたちを見るためのもの）
・写真・動画をアルバムとして残す
・戒名（この子だけの6字）を選ぶ、またはお寺からいただいた戒名に書きかえる

■ 100%ローカル・アカウント不要
このアプリは、名前も写真も記録も、すべてこの端末の中だけに保存します。アカウント登録は不要、広告もアクセス解析もありません。バックアップは、あなた自身の操作でいつでも書き出せます。

大切な人やペットを亡くすことは、「乗り越える」ものではなく、行きつ戻りつしながら、ゆっくり向き合っていくものだと私たちは考えています。だから、このアプリには目標もランキングも達成度もありません。ただ、あなたとその子だけの、静かな時間があります。
```

## キーワード（100字以内・カンマ区切り・非公開項目）

```
ペット,供養,お参り,グリーフケア,ペットロス,天国,仏壇,位牌,戒名,手紙,追悼,メモリアル,癒し,日記
```
※ App Store Connectの入力欄で文字数が超過したら、優先度の低いもの（癒し・日記あたり）から削る。

## 年齢制限（Age Rating）

Appleの年齢制限アンケートは暴力・性的表現・下品な表現・ギャンブル・恐怖表現などを問うもので、
このアプリはいずれにも該当しない（死別というテーマは扱うが、Appleの質問項目が指す
「Horror/Fear Themes」等は、驚かせる・怖がらせる演出のことで、本アプリの静かな内容とは異なる）。
実際の申告は質問票に沿って一つずつ「いいえ」を選んでいけば、4+相当になる見込み。

## App Privacy（プライバシー"栄養成分表示"）

`privacy.html`に書いた内容と一致させる。すべての項目で「データは収集されません
（Data Not Collected）」を選べる：

| Appleの分類 | 収集有無 | 根拠 |
|---|---|---|
| 連絡先情報 | 収集しない | 登録項目自体が存在しない |
| 健康・フィットネス | 収集しない | 対象機能なし |
| 財務情報 | 収集しない | 課金機能なし |
| 位置情報 | 収集しない | 使用していない |
| 機密情報 | 収集しない | 該当なし |
| 連絡先（アドレス帳） | 収集しない | アクセスしていない |
| ユーザーコンテンツ（写真・動画・メッセージ等） | 収集しない | 端末内保存のみ、送信されない |
| 閲覧履歴 | 収集しない | 該当なし |
| 検索履歴 | 収集しない | 該当なし |
| 識別子 | 収集しない | 広告ID・端末IDとも未使用 |
| 購入情報 | 収集しない | 無料・課金機能なし |
| 使用状況データ | 収集しない | 解析SDK未使用 |
| 診断情報 | 収集しない | クラッシュ収集SDK未使用 |

（参考：Google Fontsの読み込みでIPアドレスがGoogleへ渡る点は`privacy.html`で開示済みだが、
これはアプリ自身が収集・保持するデータではないため、上表の「収集しない」の判断とは矛盾しない）

## スクリーンショット（6.9インチ／1320×2868、用意済み）

Playwrightで実際の画面から生成。ダミーデータ（ペット名「モコ」、おまいり通算21回、
30日分の気分記録など）で、実際の使用感が伝わる状態にしてある。

1. `01-home.png` — おうち（プロフィールと戒名）
2. `02-omairi.png` — おまいり（4つのお供え）
3. `03-niwa.png` — おまいりの庭（増えていく花、節目までの日数）
4. `04-jibun.png` — じぶん（気分の波グラフ、この子の名で締める一言）

必要なら5枚目（アルバムまたはうごく）も追加できる。文字を重ねたマーケティング用の
バージョンが必要であれば、別途デザインする。
