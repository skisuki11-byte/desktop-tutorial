# 集計先（Google Apps Script）の設定

申し込みは、役員の Google アカウントのスプレッドシートに貯まります。サーバー代はかかりません。
作業は 15 分ほどで、プログラムを書く必要はありません。

## 1. スプレッドシートを作る

1. 役員の代表者の Google アカウントで Google ドライブを開き、「新規」→「Google スプレッドシート」
2. 名前を「春高タオル 申し込み」などにする

## 2. スクリプトを入れる

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」
2. エディタの `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` の中身を貼り付けて保存（💾）
3. 左の歯車（プロジェクトの設定）→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック
   → エディタに出た `appsscript.json` の中身を、このフォルダの `appsscript.json` で置き換えて保存

## 3. 合言葉を決める

役員だけが集計画面を開けるようにする合言葉です。

1. 同じ「プロジェクトの設定」の下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
2. プロパティ：`ADMIN_PASS`　値：役員で決めた合言葉（8文字以上を推奨。例：`haruko-2027-towel`）
3. 合言葉は役員の LINE グループの中だけで共有する

合言葉を変えたいときは、ここの値を書きかえるだけです（保存した時点で効きます）。
20 回続けて間違えると、10 分間は集計画面に入れなくなります（総当たり対策）。

## 4. シートを準備して、動作を確かめる

1. エディタ上部の関数の選択で `setup` を選んで「実行」
2. 初回は権限の確認が出るので、役員の代表者のアカウントで許可する
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「（プロジェクト名）に移動」→「許可」
   - 求められる権限は「このスプレッドシートの読み書き」だけです（メール送信やドライブ全体へのアクセスはしません）
3. シートに「申込」タブができ、見出しが並べば成功
4. 関数 `testSubmit` を「実行」→ テストの申し込みが1行入り、状態が「取り消し」になれば成功（その行は消してかまいません）

## 5. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」→ 種類の選択（歯車）で「ウェブアプリ」
2. 次のユーザーとして実行：**自分**
3. アクセスできるユーザー：**全員**（ご家庭は Google にログインせずに申し込めます）
4. 「デプロイ」を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー

「全員」にしても、だれでも読めるのは「自分が申し込んだ1件」だけです。一覧は合言葉がないと返しません。

## 6. 画面に URL と案内を設定する

`towel/js/config.js` を開いて書きかえます。

| 項目 | 書くこと |
|---|---|
| `endpoint` | 5 でコピーした URL |
| `team` | 例：`'〇〇高校 男子バレーボール部'` |
| `price` | 1枚の値段（円）。決まっていなければ `0` のまま |
| `deadline` | 締切日。例：`'2026-12-10'` |
| `delivery` / `payment` / `contact` | 受け取り方・支払い方・問い合わせ先（空なら出ません） |
| `target` | 業者の最低ロットなど、発注の目安枚数（集計画面にあと何枚かが出ます） |
| `sheetUrl` | 1 のスプレッドシートの URL（集計画面にボタンが出ます。開けるのは共有した役員だけ） |

`endpoint` が空のあいだは「デモ表示」で、入力はその端末の中にしか残りません。

## 7. 配る

- **ご家庭に送る URL**：`…/towel/`（申し込み画面。役員のページへのリンクはありません）
- **役員だけで共有する URL**：`…/towel/admin.html`（合言葉の入力から始まります）

役員がほかにもいるときは、スプレッドシートを「共有」で役員に追加しておくと、集計画面が使えないときもシートで確認できます。

## 運用のメモ

- 締切を待たずに受付を止めたいときは、`config.js` の `accepting` を `false` にする
- 締切後に届いた申し込みは、集計画面に「締切後」の印がつきます
- 役員はシートを直接直してもかまいません（集金・受け渡しのチェック、枚数の修正）。集計画面にそのまま出ます。ただし行の削除ではなく「状態」を「取り消し」にしてください（受付番号がずれないように）
- 列「requestId」「token」は非表示にしてあります。ご家庭があとから修正するための合鍵なので、消したり見せたりしないでください
- `Code.gs` を直したら、「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」で更新（URL は変わりません）
- 行事が終わったら、個人情報を残さないようにシートを削除する

## 上限

- Google Apps Script の無料枠で十分に動きます（部活の保護者会の規模なら、上限に届くことはまずありません）
- 申し込みは 1 時間に 300 件まで（いたずら対策。超えると「少し時間をおいて」と表示）
- 1 件で申し込める枚数は、画面では `maxPerOrder`（初期値 20 枚）まで。それより多い分は役員が「代わりに追加」できます
