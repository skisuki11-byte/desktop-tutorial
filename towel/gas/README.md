# 集計先（Google Apps Script）の設定

申し込みは、役員の Google アカウントのスプレッドシートに貯まります。サーバー代はかかりません。
作業は 10 分ほどで、プログラムを書く必要はありません。**パソコンのブラウザで**行ってください（スマホでは Apps Script の画面が使いにくいため）。

## 1. スプレッドシートを作る

1. 役員の代表者の Google アカウントでログインしたブラウザで https://sheets.new を開く（新しいスプレッドシートができる）
2. 左上の「無題のスプレッドシート」を「春高タオル 申し込み」などに変える

## 2. スクリプトを入れる

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」
2. 別のタブで https://github.com/skisuki11-byte/desktop-tutorial/blob/main/towel/gas/Code.gs を開き、右上の「Copy raw file」（四角が2つ重なったアイコン）でコードをコピー
3. Apps Script の `コード.gs` に最初から入っている3行（`function myFunction() {` …）を全部消して、貼り付ける
4. 保存（💾 または Ctrl+S／⌘+S）

> 1行目の `/** @OnlyCurrentDoc */` は、このスクリプトが触れるのを「このスプレッドシートだけ」に絞る印です。消さないでください。

## 3. 合言葉を決める

役員だけが集計画面を開けるようにする合言葉です。

1. Apps Script の左の歯車（プロジェクトの設定）→ いちばん下の「スクリプト プロパティを追加」
2. プロパティ：`ADMIN_PASS`　値：役員で決めた合言葉（日本語でもかまいません）
3. 「スクリプト プロパティを保存」
4. 合言葉は役員の LINE グループの中だけで共有する

- 集計画面では、大文字・小文字、全角・半角、ひらがな・カタカナの違いは同じとみなします（例：`towel` なら `TOWEL`・`ｔｏｗｅｌ` でも入れます）
- 変えたいときは、ここの値を書きかえるだけです（保存した時点で効きます）
- 20 回続けて間違えると、10 分間は集計画面に入れなくなります（総当たり対策）

## 4. シートを準備する（初回の許可）

1. 左の `<>`（エディタ）に戻り、上の関数の選択で `setup` を選んで「実行」
2. 「承認が必要です」→「権限を確認」→ 代表者のアカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」
   - 自分で作ったスクリプトなので、この表示は毎回出ます。求められる権限は「このスプレッドシートの表示と管理」だけです
4. スプレッドシートに戻ると「申込」タブができていれば成功
5. 関数 `testSubmit` を選んで「実行」→「申込」にテストの行が1行入り、状態が「取り消し」になれば成功（その行は消してかまいません）

## 5. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 「種類の選択」の歯車 →「ウェブアプリ」
3. 説明：`春高タオル`（なんでも可）
4. 次のユーザーとして実行：**自分**
5. アクセスできるユーザー：**全員**（ご家庭は Google にログインせずに申し込めます）
6. 「デプロイ」→ 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー

「全員」にしても、だれでも読めるのは「自分が申し込んだ1件」だけです。一覧は合言葉がないと返しません。
コピーした URL をブラウザで開いて `{"ok":true,"app":"towel"}` と出れば、公開できています。

## 6. 画面に URL と案内を設定する

`towel/js/config.js` を書きかえます。

| 項目 | 書くこと |
|---|---|
| `endpoint` | 5 でコピーした URL |
| `team` | 例：`'〇〇高校 男子バレーボール部'` |
| `price` | 1枚の値段（円）。決まっていなければ `0` のまま |
| `deadline` | 締切日。例：`'2026-12-10'` |
| `delivery` / `payment` / `contact` | 受け取り方・支払い方・問い合わせ先（空なら出ません） |
| `target` | 業者の最低ロットなど、発注の目安枚数（集計画面にあと何枚かが出ます） |
| `sheetUrl` | 1 のスプレッドシートの URL（集計画面にボタンが出ます。開けるのは共有した役員だけ） |

`endpoint` が空のあいだは「デモ表示」で、入力はその端末の中にしか残りません。

## 7. 配る

- **ご家庭に送る URL**：`…/towel/`（申し込み画面。役員のページへのリンクはありません）
- **役員だけで共有する URL**：`…/towel/admin.html`（合言葉の入力から始まります）

ほかの役員にも、スプレッドシートを「共有」で追加しておくと、集計画面が使えないときもシートで確認できます。

## 運用のメモ

- 締切を待たずに受付を止めたいときは、`config.js` の `accepting` を `false` にする
- 締切後に届いた申し込みは、集計画面に「締切後の申し込み」の印がつきます
- 役員はシートを直接直してもかまいません（集金・受け渡しのチェック、枚数の修正）。集計画面にそのまま出ます。ただし行の削除ではなく「状態」を「取り消し」にしてください（受付番号がずれないように）
- 列「requestId」「token」は非表示にしてあります。ご家庭があとから修正するための合鍵なので、消したり見せたりしないでください
- `Code.gs` を直したら、「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」で更新（URL は変わりません）
- 行事が終わったら、個人情報を残さないようにシートを削除する

## 上限

- Google Apps Script の無料枠で十分に動きます（部活の保護者会の規模なら、上限に届くことはまずありません）
- 申し込みは 1 時間に 300 件まで（いたずら対策。超えると「少し時間をおいて」と表示）
- 1 件で申し込める枚数は、画面では `maxPerOrder`（初期値 20 枚）まで。それより多い分は役員が「代わりに追加」できます
- `appsscript.json` はタイムゾーンと権限を明記した控えです。貼り替えなくても動きます
