# 予想問題アプリ

紙の予想問題（`../yosou/`）と**同じ中身**を、スマホで解くための画面にしたもの。
問題データは `../yosou/data*.js` をそのまま読み込むので、片方を直せば両方に反映される。

## 2つのモード

| | 学習モード | 本番モード |
|---|---|---|
| 進み方 | 1問ずつ。選んだ瞬間に正誤と解説が出る | 通しで50問。途中で答えは見られない |
| 時間 | 計らない | 60分のカウントダウン。超過しても続けられる |
| 採点 | その場（上部に「正解◯」を出す） | 最後にまとめて。100点満点 |
| 終わったあと | **間違えた問題だけをやり直せる** | 間違えた問題を解説つきで見直せる |
| 途中でやめたら | ホームから「つづきから」と「はじめから解き直す」を選べる | 「つづきから」のみ |
| リード文 | 大問が変わったとき自動で開く | たたんだまま |

記録はモードごとに別に持つ。保存の鍵は本番が `"1"`〜`"3"`、学習が `"L1"`〜`"L3"`。
本番を昔のままの鍵にしてあるので、モードを足しても前の記録が消えない。

「はじめから解き直す」は答えを消す。残したまま問1に戻っても答え合わせが見えるだけで
解き直しにならないため。押し間違えると解いた分が消えるので、必ず確認を挟む。

一方、結果画面の「間違えた◯問をやり直す」では記録の答えを**消さない**。消すと途中でやめたときに
「間違い◯問」が分からなくなるため、「この回で答え直したか」（`cur.redone`）を
別に持って、表示だけ未解答に戻している。

## 紙と違うところ

| | 紙 | アプリ |
|---|---|---|
| リード文 | 大問の先頭に印刷 | 折りたたみ。**設問の「下線部a」を押すと開いて該当箇所が光る** |
| 採点 | 自分で正解一覧と照合 | 自動。大問ごと・形式ごとの正答率まで出る |
| 見直し | 解説ページをめくる | 間違えた問題だけを順に、選択肢の色つきで |
| 1問ずつの答え合わせ | 解説ページを行き来する | 学習モードなら選んだ瞬間に出る |
| 途中で中断 | できない | いつでも中断でき、続きから再開できる |

## 作り

```
node build.js     # dist/index.html と ../sekaishi/yosou/index.html を書き出す
npm install       # test.js / shot.js に要る playwright を入れる
node test.js      # ブラウザで通しの動作を確認（87項目）
node shot.js      # 画面のスクリーンショット（s*.png、git には入れない）
```

| ファイル | 中身 |
|---|---|
| `index.html` | 7つの画面のマークアップ。学習（解答／結果）、本番（解答／解答一覧／採点結果）、ホーム、見直し |
| `app.css` | 一問一答アプリと同じ色・書体。本文は明朝、操作系はゴシック |
| `app.js` | 状態・タイマー・採点・保存 |
| `build.js` | `../yosou/data*.js` を読み込んで1ファイルに束ねる |

## 記録の保存

`localStorage` に置き、書けない環境では `sessionStorage` に落とす。
モード×3回分それぞれの「解答・現在位置・経過時間・採点結果」を持つ。
選んでいたモードも覚えるので、開き直すと前の続きから始められる。
画面を離れるとき（`pagehide` / `visibilitychange`）にも書き出すので、
途中で閉じても続きから再開できる。

## 色の決め方

回ごとに色を固定している（第1回＝青、第2回＝橙、第3回＝オリーブ）。
大問ごとに色を変えると8問おきに画面の色が変わって落ち着かないため、
いま何問目かは上部のバーと進捗バーで示している。
