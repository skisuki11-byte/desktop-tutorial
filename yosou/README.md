# 令和8年度（2026年9月）基礎学力到達度テスト 世界史探究 予想問題（全3回）

印刷して使う紙の予想問題。1回50問・100点満点を3回分。**令和3〜7年度の実物271問**を1問ずつ分析し、
その実測値にそろえて作った。令和3・4年度は問題冊子の写真57枚から全114問の設問形式を数え直してある
（`kako/r3r4.json`）。令和5・6・7は `sekaishi-app/exam-index.json`。

## 実物にそろえたもの

| | 実物（令和3・4の114問） | 本問題（各50問） |
|---|---|---|
| リード文＋下線部 | 全大問 | 全大問（下線部a〜h・空欄Ａ〜Ｆ） |
| 空欄補充 | 18% | 14〜16% |
| 正誤の組合せ | 14% | 14% |
| 年代整序 | 8% | 10〜14%（練習効率のため多め） |
| 6択の設問 | 11% | 10〜14% |
| 図版・略地図 | 8% | 8〜10% |
| 史料 | 4% | 2% |

組合せ・正誤・空欄補充の選択肢は、実物と同じく規則的な順（正正／正誤／誤正／誤誤、Ａの2値×Ｂの2値）に並べている。

## 3回で一組にしている理由

当日どちらに振れても対応できるよう、3つの筋書きに分けている。

| 回 | 筋書き | 配分の重心 |
|---|---|---|
| 第1回 | 直近の反動 | 令和7で手薄だった明清・古代オリエント・宗教改革を厚く |
| 第2回 | 傾向の継続 | 令和7の配分をそのままなぞる（ギリシア・ローマ8問、大航海4問） |
| 第3回 | 取りこぼしと範囲拡大の保険 | 第1・2回で扱わなかった知識を全部入れ、大問6を19世紀に |

3回あわせると、過去5年の実物を解くのに必要な知識（令和7型の範囲で668語）の **100%** に触れる。
1回だけでは53%／46%／31%にしかならないので、3回とも解く前提で作ってある。

## 作り

| ファイル | 中身 |
|---|---|
| `data.js` `data2.js` `data3.js` | 各回50問の本文・選択肢・正解・解説・「予想の根拠」と図版のSVG |
| `build.js` | 組版。正解の偏りを直す回転処理を含む |
| `style.css` | A4・縦・1段組みの版面 |
| `yosou.html` | 書き出し（ブラウザで開いて印刷。右下に印刷ボタン） |
| `rotate.js` | 正解の偏りを直す回転処理（build と verify が共有） |
| `verify.js` | 自己点検。分野別・形式別の集計を `bunya.json` に書き出す |
| `bunya.json` | 過去問インデックスの集計結果。予想根拠の表はこれから組み立てる |
| `yosou.html` `yosou-2.html` `yosou-3.html` | 書き出し（ブラウザで開いて印刷。右下に印刷ボタン） |

```
node verify.js               # 3回分をまとめて点検 → bunya.json を更新（異常があれば終了コード1）
node build.js 1 && node build.js 2 && node build.js 3
node pdf.js                  # PDF を書き出す（要 playwright）
```

## 自己点検（`verify.js`）

- 問数50・番号の連番・選択肢4つ・正解番号の範囲・選択肢の重複・空欄・図版の参照
- **解説の丸数字が正解の番号を指していないか**（回転処理が壊れると必ずここに出る）
- 過去問インデックスへの分野の割り当てに、重複や取りこぼしがないか
- **正解の選択肢だけが長くなっていないか**（平均差2.5字超、または5字以上長い設問が4問以上でNG）
- **過去問の必要知識をどれだけ覆えているか**（3回あわせて何%か）
- 予想根拠の表の数値は、手で数えずこの集計結果（`bunya.json`）から組み立てる

## 正解の回転について

手で作ると正解が①に寄る（初稿では50問中35問が①だった）。`build.js` は固定の並び
`[1,3,2,4,2,1,4,3]` にそって各問の選択肢を回転させ、①〜④が12・13・13・12問になるよう
ならしている。解説中の丸数字も同じだけずらすので、書き換えても解説と選択肢はずれない。
ア〜エを選ぶ略年表の問題だけは、並びに意味があるので回転させない。

## 予想の考え方

1. 大問構成は令和7年度の実物にそろえる（第1〜5問が必須で各8問、第6問が選択のテーマ史10問）。
2. 3年連続で出ている分野は今年も出る。
3. 直近の令和7年度で手薄だった分野は反動で厚くなりやすい（明・清、古代オリエント、宗教改革）。
4. 難易度は教科書レベル〜共通テスト相当。奇問は入れない。

各設問の解説末尾に、その問題を予想した根拠（過去問の年度と設問番号）を書いてある。
的中を保証するものではない。
