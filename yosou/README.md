# 令和8年度（2026年9月）基礎学力到達度テスト 世界史探究 予想問題

印刷して使う紙の予想問題（全50問・100点満点）。`sekaishi-app/exam-index.json`（令和5・6・7年度の
実物157問のインデックス）を分野別・形式別に数え直し、その実測値にそろえて作った。

## 作り

| ファイル | 中身 |
|---|---|
| `data.js` | 全50問の本文・選択肢・正解・解説・「予想の根拠」と、図版6点のSVG |
| `build.js` | 組版。正解の偏りを直す回転処理を含む |
| `style.css` | A4・縦・1段組みの版面 |
| `yosou.html` | 書き出し（ブラウザで開いて印刷。右下に印刷ボタン） |
| `rotate.js` | 正解の偏りを直す回転処理（build と verify が共有） |

| `bunya.json` | 過去問インデックスの集計結果。予想根拠の表はこれから組み立てる |
| `yosou.html` | 書き出し（ブラウザで開いて印刷。右下に印刷ボタン） |

```
node verify.js       # 点検 → bunya.json を更新（異常があれば終了コード1）
node build.js        # yosou.html を書き出す
node shot.js         # 確認用のスクリーンショットと PDF（要 playwright）
```

## 自己点検（`verify.js`）

- 問数50・番号の連番・選択肢4つ・正解番号の範囲・選択肢の重複・空欄・図版の参照
- **解説の丸数字が正解の番号を指していないか**（回転処理が壊れると必ずここに出る）
- 過去問インデックスへの分野の割り当てに、重複や取りこぼしがないか
- 予想根拠の表の数値は、手で数えずこの集計結果（`bunya.json`）から組み立てる

## 正解の回転について

手で作ると正解が①に寄る（初稿では50問中35問が①だった）。`build.js` は固定の並び
`[1,3,2,4,2,1,4,3]` にそって各問の選択肢を回転させ、①〜④が12・13・13・12問になるよう
ならしている。解説中の丸数字も同じだけずらすので、書き換えても解説と選択肢はずれない。
ア〜エを選ぶ略年表の問題だけは、並びに意味があるので回転させない。

## 予想の考え方

1. 大問構成は令和7年度の実物にそろえる（第1〜5問が必須で各8問、第6問が選択のテーマ史10問）。
2. 3年連続で出ている分野は今年も出る。
3. 直近の令和7年度で手薄だった分野は反動で厚くなりやすい（明・清、古代オリエント、宗教改革）。
4. 難易度は教科書レベル〜共通テスト相当。奇問は入れない。

各設問の解説末尾に、その問題を予想した根拠（過去問の年度と設問番号）を書いてある。
的中を保証するものではない。
