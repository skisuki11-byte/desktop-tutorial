YouTube Data API v3 ／ YouTube Analytics API v2

自分のチャンネルを、公式のデータで分析する

視聴回数・総再生時間・視聴維持率・流入経路・検索語まで、YouTube 公式のAPIから直接読み取ります。 データはこのブラウザの中だけで処理され、どこにも送られません。

準備の手順を読む

はじめに「設定」でクライアントIDを登録してください。Google Cloud で自分用に1つ作ります（無料・5分）。

できること

  • 期間ごとの視聴回数・総再生時間・平均視聴時間の推移と、前の期間との比較
  • 動画1本ごとの視聴維持率グラフ（どこで離脱したか）
  • 流入経路の内訳と、YouTube検索で実際に使われた語
  • 国・デバイス・再生場所・登録者／非登録者の別
  • 題名・説明文・タグの作りの点検

できないこと

  • vidIQ 本体への接続。vidIQ は外部向けのAPIを公開していません
  • 他人のチャンネルの成績。視聴維持率や流入は所有者しか取得できません（これは vidIQ でも同じ）
  • キーワードの検索ボリューム推定。YouTube は公開していません（vidIQ の数値も独自推定です）

データの扱い

  • 通信は ブラウザ → Google の直通。当方のサーバーは経由しません
  • アクセストークンは保存しません。タブを閉じれば消えます
  • 読み取り専用の権限しか要求しません。動画の変更・削除はできません

クライアントID

Google Cloud で自分用に1つ作った「OAuth クライアントID」を入れてください。 秘密の値ではありませんが、この端末の中にだけ保存します。作り方は README の手順1〜4にあります。

取得済みのデータ

同じ問い合わせは30分ぶんだけ手元に貯めています。1日に使える問い合わせ回数には上限があるためです。 最新にしたいときは上の「↻」か、こちらから消してください。

要求している権限

  • youtube.readonly … 動画の一覧・題名・説明文・タグを読む
  • yt-analytics.readonly … 自分のチャンネルの成績を読む

どちらも読み取り専用です。動画の投稿・変更・削除はこのアプリではできません。
